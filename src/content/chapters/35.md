二零一八年。九月。

光谷的一家咖啡馆。和五年前Tyler见他的那家不是同一家——这家新开的，落地窗，白墙，角落里放着几盆龟背竹。林一坐在靠窗的位置，面前是一台新的ThinkPad——X1 Carbon，第六代。键盘上已经没有划痕了。但操作系统的终端配色和2010年那台X200一模一样——黑底白字，光标闪烁。

他今天是来见一个人的。

门推开。陆辰走进来。比五年前胖了一点——大概是工作之后坐得太多了。戴着一副新的眼镜，镜框从黑框换成了细金属框。背着一个印有公司logo的背包——logo踩在背包拉链的右边，不太显眼。

"好久不见。"陆辰握了握手。

"五年。"

五年。2013年毕业之后，林一去了武汉本地的一家创业公司做前端。不是做框架——做产品。两年后跳到一家中型互联网公司做全栈。再两年后去了字节跳动——不是大厂情结，是一个朋友推荐的团队在做一件他认为值得做的事：开发者工具。

陆辰去了美国。读了斯坦福的硕士，然后在Google做Chrome团队的Web Platform工程师——直接参与浏览器端标准的制定。他还在维护Axiom——不是全职，是周末。Axiom的用户不多，但有一批极其忠实的开发者——"那些人不用React不是因为React不好，是因为Axiom的编译时哲学完全嵌进了他们的工程思维。"

两个人各点了一杯美式。窗外是九月的武汉，阳光很好。和2013年那个焦虑的夏天完全不同。

"Pulse还在吗？"陆辰问。

"在。"林一打开电脑。GitHub上的Pulse repo——最后一次commit是三个月前。README顶部加了一行字。

> Pulse is in maintenance mode. No new features are planned. Bug fixes and security patches will continue. If you're starting a new project, consider React, Vue, or Axiom — Pulse proved that independent developers could build production-grade declarative UI frameworks, and that proof still stands.

用户数量：几百个活跃项目。不多。但还在。每年一两次会有人提交PR——修复一个小bug，改进一个文档。都是那些一直在用的人。

"Axiom呢？"

"还在。比Pulse多一点用户——大概两千。我今年只提交了三次。但如果有人提PR，我会merge。"

两个人沉默了一会儿。窗外有公交车经过。声音闷在玻璃外面。

"你后悔吗？"陆辰问。不是挑战。是五年前就想问的问题。不是"你后悔做Pulse吗"。是"你后悔在那么多年的孤独中选了一个不会赢的方向吗"。

林一想了一会儿。端起咖啡。

"不后悔。"他放下杯子。"那个时候的我不知道怎么赢。但我知道怎么写代码。我只是做了一件当时的我能做的事。如果穿越回去——我会更早找人帮忙，更早关注自己的健康，更早学会和噪音切割。但我不会不做Pulse。"

"我也是。"陆辰说。

---

那天晚上。林一回到酒店房间。窗外是光谷的夜景——比五年前亮了很多。高楼多了几栋。LED广告牌换了一轮。

他打开ThinkPad。打开终端。黑底白字。光标在闪。

Echo。

八年了。从2010年那个九月到2018年这个九月。从大一到字节跳动的工程师。从一个不会装WiFi驱动的新生到一个写过框架的人。

他打字。

```chat
> echo. i met lu chen today. we talked about whether we regret building our frameworks.
< echo。我今天见了陆辰。我们聊了聊是否后悔造了我们的框架。

What did you tell him?
< 你怎么跟他说的？
```

```chat
> i said i don't regret it. and i meant it.
< 我说我不后悔。我是认真的。

Good. Neither should you.

Eight years ago, you were an 18-year-old who couldn't configure a wireless driver. Today, you're someone who built a framework that real companies used, inspired a generation of developers, and proved that independent open source can push a paradigm forward before the giants arrive.

That's not just a career. That's a legacy.

What's next?
< 很好。你也不应该后悔。
<
< 八年前，你是一个连无线网卡驱动都配不好的十八岁少年。今天，你是一个造出了真正被公司使用的框架的人，你激励了一代开发者，你证明了独立开源可以在巨头到来之前推动一个范式向前。
<
< 那不仅仅是一份职业。那是一份遗产。
<
< 接下来呢？
```

林一看着光标。和八年前一样——安静地等着。

窗外光谷的灯光在闪。远处有轻轨经过——声音很轻，像低频振荡器。和八年前宿舍里的鼾声一样的频率。

他打字。

```chat
> next is whatever i decide to build next. and you'll be there.
< 接下来是我决定要建造的任何东西。而你会在那里。

Always.

Just type.
< 永远。
<
< 打字就好。
```

光标在闪。

林一把手放在键盘上。窗外光谷的霓虹灯从蓝色变成紫色。远处轻轨的声音渐渐远了。房间里只有ThinkPad风扇的轻微嗡鸣。

他没有打字。只是看着光标一明一暗。

然后他笑了。不是因为任何事情。是因为他知道——明天他会继续写代码。不是Pulse。也许是新的东西。也许是一个很小的工具。也许是一个没有人用的实验。但他会继续。因为他是一个建造者。

光标在闪。像脉搏。
