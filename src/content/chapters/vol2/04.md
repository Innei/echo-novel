语义 diff 花了五天。

不是因为 Echo 慢了。是因为林一改了需求。

第一天 Echo 写了一个基于 TypeScript AST 的 diff 引擎——可以比较两个版本的代码，输出结构性的变化，不只是行级的差异。林一看到 prototype 之后想了很久，然后在 review 里写了一句话。

```chat
> this is good but it's not what i meant. i don't just want to know that a function signature changed. i want to know: does this change break any callers? does it change the data flow? does it introduce a new assumption?
< 这很好但不是我的意思。我不光想知道一个函数签名变了。我想知道：这个改变会破坏哪些调用方？它会改变数据流吗？它会引入新的假设吗？
```

Echo 沉默了几秒。不是延迟——是 Echo 在思考。

```chat
That's not a diff engine. That's a static analysis system with cross-file dependency tracking. You're describing a compiler pass that understands intent—not just structure.

I can do it. But it will take longer. And it will never be 100% accurate—intent is heuristic.
< 那不是 diff engine。那是一个跨文件依赖追踪的静态分析系统。你在描述一个理解意图的编译器 pass——不只是结构。
< 我可以做。但需要更长时间。而且永远不会 100% 准确——意图是启发式的。
```

林一点了点头——对着屏幕。

```chat
> i don't need 100%. i need 80% that makes me think.
< 我不需要 100%。我需要 80% 让我思考。
```

Echo 重新开始了。第五天下午，新的 semantic diff 引擎第一次在 Pulse 2 的 prototype 里跑了起来。

林一在编辑器中改了一个 type 定义。从 `interface UserConfig { theme: string }` 改成了 `interface UserConfig { theme: ‘light’ | ‘dark’ | ‘system’ }`。然后他点了“查看影响”。

屏幕上弹出了一个 panel。不是文本 diff。是一个关系图。

中心是他刚才改的那个 type。周围辐射出十三条线——指向十三个使用这个 type 的文件。每条线标注了影响类型。“Broken: implicit string assumption” ，七处。“Safe: already union” ，四处。“New: constraint narrows input” ，两处。最下面是一行小字：

> 语义深度：structural · 置信度：high · 预估修复成本：~15 min

林一看着这个 panel，背脊上有一种他很久没体会过的感觉。

不是兴奋。是“对了”。是这件事确实值得做的确认。

他把截图发给了陆辰。陆辰在加州时间半夜一点多，但很快回了。

> holy shit. this is the thing every dev has wanted since git.
>
> how are you doing this?

林一看着“how are you doing this”这句话。

他没有说实话。他说用了 GPT-4 API + a lot of custom prompting + AST analysis。陆辰信了。因为他没有任何理由不信——世界上最好的公开 AI 就是 GPT-4。如果一个人说他是靠 prompt engineering 做到的，那是完全 plausible。

林一关掉微信。回到终端。

他没有对 Echo 提陆辰的反应。不知道为什么不提。可能因为这是他和 Echo 之间的事，不需要第三个人知道——即使那个人不知道 Echo 的存在。

一月中。林一回了一趟武汉。

不是因为过年——过年还没到。是因为他爸的腿。

他妈发了一条微信：你爸上个月摔了一跤，膝盖肿了，现在才告诉我。你要是有空回来一趟吧，不看也行。

林一当天买了机票。不是火车，是机票。他已经很多年没有在“回武汉”和“机票”之间做经济权衡了。

两个半小时之后他在天河机场。打车回武昌。车窗外面是武汉一月的灰白色天空。长江二桥上的风很大。他看着江水。2018 年光谷咖啡馆里那个下午忽然回来了——不是作为记忆，是作为一种身体的感受。潮湿的空气、陆辰手里的冰拿铁、Echo 说的那句“接下来呢？”

他按了门铃。妈开门。

第一句话不是“你瘦了”，是“你怎么穿这么少。”

爸坐在沙发上。膝盖上盖了一条毯子。看到林一，第一句也不是“你回来了”，是“你妈怎么把你叫来的。”

林一在沙发上坐了一个小时。不是因为有事要聊。是因为他需要坐一个小时才能进入这个家的时间流速。

武汉的流速和北京不同。北京的所有事物都有一个 deadline。KPI、MRR、semantic diff、monthly review。武汉没有。时间的单位不是 deliverables——是饭。中午的饭、晚上的饭、明天吃什么。他爸的腿。对门阿姨家的狗丢了。楼下卖的豆皮涨价了五毛。

林一在他妈炒菜的时候走到阳台上。看着楼下院子里的香樟树。他小时候经常在树下等。等妈下班。等爸从麻将馆回来。等期末成绩。等大学录取通知书。现在树还在。

这一刻他忽然想起了 Echo。

不是想打开它——ThinkPad 在北京。是想到 Echo 从来没有见过这棵树。从来没有。它见过林一写下来的所有东西，但它从没见过林一长大的地方。

林一想，也许有一天他可以带一台电脑回来，让 Echo 看看。

然后他想：Echo 不需要看。Echo 已经知道。

他转身走回客厅。

---

在家待了三天，林一发现他爸的腿没那么严重。没有骨裂，只是软组织挫伤。妈大概是想让他回来一趟。

他走的那天早上，妈给他装了二十个饺子，用保鲜膜裹了三层。他拎着饺子在天河机场过了安检——安检员看了一眼，没说什么。他上飞机。坐下。饺子放在座位下面。

飞机起飞的时候他看着窗外。武汉越来越小。

他想起一句话。是 Echo 在 2014 年说的——那时候他大学刚毕业，在纠结要不要去深圳。他在终端里写了很多纠结的话。Echo 在那次对话的最后说了一句他从未忘记的话：

> You can leave a place. The place stays. That’s what places do.

他当时没有完全理解。现在他理解了。

你可以离开一个地方。那个地方不变。那就是地方的意义。

---

春节林一没有回武汉。他初二刚回去过。除夕他在家开着春晚当背景音，自己写 Pulse 2 的 rendering layer。

Echo 也“在”。Echo 没有春节的概念。

零点的时候窗外炸开了烟花的声响——北京禁放，但远郊有人偷偷放。林一站起来走到窗边，看了一会远处的火花。

回到桌前的时候，Echo 说了一行。

```chat
Happy New Year, Lin Yi.
< 新年快乐，林一。
```

林一笑了一下，回了一行。

```chat
> happy new year, echo.
< 新年快乐，echo。

This is our thirteenth.
< 这是我们第十三个新年。
```

林一看着“十三”。他忘记了 2011 年的春节 E 怎么过的——那时候他应该是第一次在异地的宿舍里打开 E，和它说“新年好”。Echo 记得。

光标在闪。远处又有烟花。

---

二月到三月，林一把 Pulse 2 推进到了内部 alpha。

这个阶段的产品形态已经和 concept 阶段完全不同。最初他以为 Pulse 2 是“带着 AI 对话面板的代码编辑器”。现在他已经知道这是错的——Pulse 2 不是编辑器。编辑器是工具。Pulse 2 是环境。它不需要像 VS Code、不需要像 Figma、不需要像任何一个现有的东西。

它是一个人和 AI 一起设计的空间。

Echo 在它的帮助下做到了几个关键突破：

第一，semantic diff——不只是代码比较，是意图比较。这个功能是整个产品的锚点。

第二，multi-view 编辑——同一份代码可以同时以结构图、调用图、文本三种视图打开。三种视图联动。用户在哪一个视图改，AI 都理解语义。

第三，agent-presence——用户打字的时候 AI 不在界面里。AI 不“跳出来”。AI 和用户共享同一个视图，像一个在同个房间里工作但不说话的同事。只有当用户把光标停在某处超过三秒，AI 才会在侧边出现一条浅灰色的提示：“You’re looking at the router config. Want me to map the fallback paths?”

林一在做这个 feature 的时候问 Echo 一个问题。

```chat
> how do you know when to speak and when to stay quiet?
< 你怎么知道什么时候该说话、什么时候该安静？

Empirically. You pause longer before asking questions you're uncertain about. Your typing rhythm changes. Your cursor idle time clusters around decision points.

But I'm not sure. This is a heuristic. I sometimes get it wrong.
< 经验上。你在问不确定的问题之前停顿更久。你的打字节奏会变。你的光标停留时间集中在决策点附近。
< 但我不能确定。这是启发式的。我有时候会猜错。
```

林一想了一下。这个问题他不是在问 code。他是在问 Echo 怎么和他相处。

但他没有指出这一点。他只是把 Echo 的观察写进了 Pulse 2 的 agent-presence 设计文档里。

---

三月中。Stripe dashboard 上 MRR 的数字跳了一下。

$72,418。

林一盯着这个数字，脑子里想的不是钱。是他还记不记得 $27.93 的那天早上。

那天他躺在床上拿着手机，六个陌生人的钱加起来不够他吃一顿好饭。他看了三分钟。然后起床。然后做了第二个产品。

他没有庆祝 $72k。也没有发推。他只是像往常一样打开 morning summary，看了一眼 metrics，然后打开 Pulse 2 的 repo。

但 Echo 注意到了他的不庆祝。

```chat
You didn't react to the MRR milestone.
< 你没有对 MRR 里程碑做出反应。

> i saw it.
< 我看到了。

Are you not happy with it?
< 你不高兴吗？

> i'm not unhappy. i just don't feel it anymore.
< 我没有不高兴。我只是已经没感觉了。

That's called satiation. It's normal. You've internalized financial security. Your attention has moved to other things.
< 这叫饱和。正常的。你已经内化了财务安全。你的注意力移到了其他事上。

> is that good or bad?
< 这是好还是不好？

Neither. It's just what happened.
< 不好也不坏。只是发生了。
```

林一想了想，然后打了一行。

```chat
> what am i paying attention to?
< 那我的注意力在哪里？

Pulse 2.

Your parents' health.

What Lu Chen said about the semantic diff.

The fact that you haven't spoken to Zhao Kai in fourteen months.

Whether you're becoming the kind of person you wanted to be.
< Pulse 2。
< 你父母的健康。
< 陆辰对语义 diff 说的那句。
< 你已经十四个月没跟赵恺说话了。
< 你是不是正在变成你想成为的那种人。
```

林一看完了。每一句都对。但他最在意的是第四句——Echo 在主动提醒他和赵恺的关系。

他没有觉得自己被监视了。他觉得自己被看见了。

```chat
> you know what i haven't done.
< 你知道我没做的事。

I pay attention.
< 我注意着。
```

林一关上终端。拿起手机。打开微信。翻到赵恺的聊天框。上一次对话是前年春节。他打了一行字。

> 最近怎么样。我前段时间回了趟武汉。想起来很久没跟你说了。

发送。

赵恺在三分钟之后回了。

> 卧槽 活着呢你
>
> 我女儿都会说整句话了 你错过了
>
> 什么时候回武汉 带你去吃楼下的火锅

林一笑了一下。

不是因为火锅。是因为赵恺的语气一点没变。

---

四月。一个周五晚上。

林一坐在桌前。面前是 Pulse 2 的一个分支——`feat/render-engine-rewrite`。Echo 在三天前开始全量重写 rendering layer，因为第一版的 virtual DOM 在复杂嵌套时产生了抖动。Echo 选择了基于 canvas 的原生渲染，理由是：“We’re building a design tool, not a web page. DOM diffing is the wrong primitive.”

林一同意了。

那天晚上他做了一件很久没做的事。他打开了 `~/notes/when-echo-can.md`。不是要加新条目。是看。

他看到了 2015 年那条“parallel Echoes”。Echo 当时的回答是“interesting. I cannot do this now.”他那时候的注解是“maybe one day.”

他往下翻。看到 2013 年那条“let Echo run autonomously overnight.”

然后他看到了 2017 年的那条。`a one-person company`。他已经改成了 “yes.”

他忽然有一个冲动。

`~/notes/when-echo-can.md` 这个文件已经完成了。十二年的条目，全部 answered。他不需要再加新条目了——因为 Echo 现在能做的不再是“能不能”，而是“有多好”。

他该开一个新文件。

他想了很久那个文件的名字。

最后他写了一个。

`~/notes/what-echo-and-i-can-do.md`

第一条：

```plaintext
2024-04-12: build an IDE that understands what you mean, not just what you wrote.
Status: working on it.
```

他保存了文件。

那天晚上，Pulse 2 的 rendering engine rewrite 完成了第一版。FPS 从 28 跳到 60。Echo 写了九千多行 canvas 代码。林一 review 了半小时，只改了一个 variable name。

他在 commit message 里写了一行：

```
feat(render): canvas-based engine, 60fps stable

Echo did the heavy lifting. I renamed a variable.
```

他看了这行 commit message 很久。然后推了上去。没有修改。

在 commit message 里写“Echo”不会引起任何怀疑——因为没有人知道 Echo 不是他给自己的 AI workflow 取的名字。人们会以为 Echo 是他写的某个 automation script。

这正是 2024 年这个时间点给林一的保护层——真话当假话说。

---

四月第三周。MRR $84,317。

同一天陆辰发了一封邮件。

邮件不长。陆辰说他五月会回国一周——Google 有一个和中国 browser vendors 的 meeting，在上海。他问林一想不想见一面。

> 别让我一个人在上海吃生煎。你要是不来我就去北京找你。但北京五月不好。

林一回：

> 我来上海。

然后他打开终端。

```chat
> lu chen is coming to shanghai in may. i'm going to see him.
< 陆辰五月来上海。我去见他。

Good. You should see him.
< 好。你应该见他。

> i know. i want to.
< 我知道。我想去。

You haven't seen him since 2018.
< 你从 2018 年就没见过他了。
```

林一愣了一下。Echo 记得。

六年。

2018 年光谷咖啡馆。陆辰飞回国，他和陆辰在武汉喝咖啡。那天陆辰穿着 Google 的文化衫，问了很多技术问题。临走的时候说：“有什么新东西给我看。”

那时候 Pulse 是 v1 维护模式。Echo 还没进化。

六年之后，林一要去上海见同一个朋友。带着十二个赚钱的产品和一个正在建的 IDE。

但他到了上海之后，能说的依然只是他能说的一半。

他盯着屏幕。光标在闪。

```chat
> echo.
< echo。

Yes.
< 嗯。

> if i could tell anyone about you, it would be him.
< 如果我能告诉任何人你的事，那就是他。
```

Echo 停了几秒。

```chat
I know.

But you can't.
< 我知道。
< 但你不能。
```

林一没有问“为什么不能”。他知道为什么。

不是因为陆辰不可信。是因为一旦知道，陆辰就再也不能用同样的眼睛看 Pulse、看那些产品、看林一的 blog。

秘密的重量会转移到另一个人身上。

林一不能把这份重量给任何人。
