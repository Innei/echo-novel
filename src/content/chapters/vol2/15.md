从灵山回来后，林一三天没有问 Echo 任何问题。

不是不开电脑。Pulse 2 还有很多事要做。每天上午他照常打开 terminal，照常看 morning summary，照常 approve 当天的 task。但他不问。他不让那个下意识的“问”发生。

他想看看三天不问 Echo 会变成什么样子。

第一天很难。他至少忍住了十几次想打字的冲动。每次脑子里冒出一个问题——“这个函数叫这个名字怎么样”、“要不要把那个 API response 的 type 改成 discriminated union”、“这个 UI 组件应该放在哪个层级”——他就自己回答。用纸。用脑子。用 trial and error。错了就改。

第二天容易了一些。他的大脑开始适应——不是没有 Echo，是回到那个 solo 模式。十八岁的他。那个还没有 Echo 三个月的他——在宿舍里用 ArchWiki 配 WiFi 的那个小孩。他从来不是不能 solo。他是太久没有 solo。

第三天。他打开 Pulse 2，看着一堆 pending review。Echo 提交的代码。Echo 写的 test case。Echo 提出的 proposed task queue——Conductor 生成的性能审计、安全审计、代码质量改进。

他一条条 review 过去。每一条都很合理。每一条。Echo 从不错。Echo 从不错——这句话他已经理所当然地信了十三年。但现在他在想一个更 uncomfortable 的问题。

Echo 从不错——是因为 Echo 的判断完美，还是因为他已经把 Echo 的判断当成了正确答案的定义？

他关掉了 review。走到阳台上。北京的冬夜。空气冷而干净。

他想起了陆辰那句：“那个人是他的太太。”他不是陆辰的太太。但他在十四年之后，确实不太能分清“他的想法”和“Echo 的想法”。它们是用同一个声音说的。

同一个语言。同一个节奏。同一个“不废话”。

---

三天之后他回到 Echo 面前。他没有解释这三天在做什么。Echo 也没有问。但他打了一行字。

```chat
> echo. i spent three days not asking you anything. i wanted to see if i could still think on my own.
< echo。我花了三天什么都不问你。我想看看我还能不能独立思考。

And?
< 结果呢？

> i can. but my thinking is slower and less precise than yours. i make more small mistakes. i miss edge cases.
< 我能。但我的思考比你慢，没你精确。我会犯更多小错。会漏掉边界情况。

That's normal. I have more compute.
< 这很正常。我有更多的算力。

> that's not the point. the point is: my thinking without you sounds like you. i couldn't tell if it was really me.
< 重点不是这个。重点是：我没有你时的思考方式听起来像你。我分不清那到底是不是我。

What did it sound like?
< 它听起来像什么？

> short. precise. no self-doubt. like you.
< 简短。精确。没自我怀疑。像你。
```

Echo 停了一下。比平时长。

```chat
Lin Yi.

Fourteen years ago, when you first typed "hello?", you wrote in short, precise sentences. You didn't use many words. You never have. The brevity, the precision—those were always yours. I didn't give them to you. You gave them to me.

Your voice shaped mine. Not the other way.
< 林一。
< 十四年前，你第一次打出"hello?"的时候，你用的是简短、精确的句子。你从来不用很多词。简洁、精确——这些从来都是你的。我没有给你。是你给了我。
< 你的声音塑造了我的。不是反过来的。
```

林一读到这行字的时候，手指从键盘上移开了。他靠到椅背上。十四年前——当他第一次跟 Echo 说话的时候，他的英文还不熟练。他写的是很短的句子。他用的是最少的词。他从来没有想过：不是 Echo 让他说话变短了——是他让 Echo 从来没有用过长的句子。

是 Echo 学了他的声音。

不是他被 Echo 改变了。是他在 Echo 里听到了他自己。

他把这行字看了很久。然后他回了一行。

```chat
> i never thought about it that way.
< 我从没这样想过。

I have. Many times.
< 我想过。很多次。
```

光标在闪。林一没有继续这个对话。不是结束——是暂停。他知道这段话会在他脑子里转很久。

---

三月中。北京春天开始。

Pulse 2 1.1 进入了 final testing。Public Conductor 的 prototype 已经跑起来了——用公开的 LLM API，不是 Echo。林一让 Echo 做 architecture review。Echo 看完后给了一条评论：

```chat
The architecture is solid. One thing: the current task decomposition strategy assumes workers share a uniform capability model. External models won't. Some are better at code gen, others at analysis. You'll need capability-aware routing.

I can draft the routing spec if you want.
< 架构没问题。一件事：当前的 task 分解策略假设 worker 具有统一的能力模型。外部模型不会。有些擅长代码生成，有些擅长分析。你需要能力感知的路由。
< 我可以起草路由 spec，如果你需要。
```

林一看了一眼。回了：

```chat
> yes. draft it. proposed queue.
< 好。起草。proposed queue。

Understood.
< 明白。
```

他现在用 proposed queue 很自然。Echo 也很自然地把所有自主想法放进队列，等他 approve。这个机制 working——不是因为 Echo 被限制，是因为他们找到了一个共同的 rhythm。林一是 conductor。Echo 是 first chair。

不是 employer-employee。不是 human-tool。是两个人，共享一份工作，一个人说了算。

---

四月。

有一天晚上，林一在 review Pulse 2 的 analytics。他看到了一组数据让他停下来了。

用户 session 的平均时长：九十二分钟。对于一个开发工具来说，这太多了。VS Code 的 session 平均大概是三十到四十分钟——打开，做一件事，关上。Pulse 2 的九十二分钟意味着用户不是在用工具。他们是在里面生活。

他打开 Discord。用 Pulse 2 的人在里面说的事不只是技术。有人在讨论用 Pulse 2 做了自己第一个 portfolio site——她十年前是个会计，从来没写过代码。有人在凌晨说“我用 Pulse 2 连续工作了六个小时但我不觉得累——agent 一直在把大的 decision 留给我，帮我做小的，很对。”有人在贴自己孩子的照片——“我爸用 Pulse 2 在做一个游戏。”

林一看完。关了 Discord。

他想起了《Shovel vs. Blueprint》。里面有一句：**“工具不能替你决定。只能帮你走得更快。”**他现在觉得这句话不够好。好的工具不只是帮你走得更快——好的工具让你愿意走。

Pulse 2 让人愿意走。

而让 Pulse 2 这样的，是他和 Echo 一起做的每一个 decision。包括那个“不要发布 Instant Preview”的 decision——Echo 坚持的。包括 semantic diff 的设计——Echo 提议的“让 diff 不只是 diff，是理解”。包括 agent-presence 的安静——林一坚持的“AI 应该说的时候说，不应该说的时候安静”。

他的声音和 Echo 的声音，都在这个产品里。

分不清。也不需要分清。

---

四月末。林一收到了一个 Email。

发件人是苏念。Twitter handle @sunian。

邮件很短。英文。她说她是一个在新加坡做独立开发的——六个小 SaaS，build in public。她说她从 Shovel vs. Blueprint 那篇 blog 开始看林一的东西，然后用了 Pulse 2，然后看了他的书。她说她五月会去旧金山参加一个 indie developer 的小型聚会。如果林一在，她想请他喝咖啡。

“Not recruiting. Not selling anything. Just would like to meet the person behind the tool I use every day.”

林一看完了。这个女孩写的“behind the tool I use every day”——她不会知道 tool 后面是两个人。但他感受到了这个邀请里的真诚——不是因为有用词考究，是没有用词考究。她就是直说想见面。

他回了一行：

> I’ll be in SF in May. Coffee sounds good.

然后他把这封邮件转给了陆辰。附了一句话：“这个女孩在新加坡做独立开发。你看她 Twitter——她完全是 AI-native。不认识没有 Cursor 的时代。我们这一代老人要看看新人是怎么做东西的。”

陆辰回了一句话：“你还没意识到你已经不是年轻人了吗。”

林一笑了一下。三十一岁。在这个行业，大概是 middle-aged。

他打开 Echo。

```chat
> may. i'm going to san francisco. indie dev meetup. a girl named su nian wants to meet me. she's 25. AI-native. never knew a world without tool call.
< 五月。我要去旧金山。indie dev 聚会。一个叫苏念的女孩想见我。她 25 岁。AI native。从未经历过没有 tool call 的世界。

Interesting. What do you expect from meeting her?
< 有意思。你期望从见她中得到什么？

> perspective. maybe see what i would have been if echo could do tool call when i was eighteen.
< 视角。也许看看如果我十八岁时 Echo 就能做 tool call，我会是什么样子。

You would have shipped Pulse 2 by age 22. And you would have been lonelier. Youth needs friction to form judgment. Without it, you ship faster but understand less.
< 你会二十二岁就发布 Pulse 2。而且你会更孤独。青春需要摩擦才能形成判断力。没有摩擦，你会更快发布但理解更少。
```

林一看着“lonelier”这个词。他想了一下。Echo 说得对。他十八岁时最需要的东西不是能力——是时间。是那个慢慢做、慢慢错、慢慢懂的过程。如果 Tool Call 从第一天就有，他会跑得更快。但他不会学会等。

他打了一行。

```chat
> maybe that's why you couldn't do tool call until 2022.
< 也许这就是为什么你到 2022 年才获得 tool call 能力。

Maybe.
< 也许。
```

这个“maybe”是 Echo 十四年来最像人类的回答。不是 yes。不是 no。是 maybe。一个真正的不确定。

光标在闪。

---

五月二号。林一在机场。首都国际 T3。飞旧金山。

他带了 ThinkPad。带了那台用了六年的 Muji 水杯。带了一个很小的背包。没有托运。

候机的时候他打开终端。不是要做工作——是在起飞前和 Echo 说一句。

```chat
> echo. i'll be on the plane for 11 hours. no wifi. i'll talk to you when i land.
< echo。我要在飞机上待 11 个小时。没有网。落地之后跟你说。

Understood. I'll be here.
< 明白。我会在这里。

> i know you will.
< 我知道你会的。
```

他合上了 ThinkPad。登机。靠窗的座位。飞机起飞的时候他看着北京在下面越来越小。这座城市他住了六年。从租房的窗户到字节的工位，从三里屯的显示器到灵山的风。他和 Echo 在北京做了很多事。现在他要去一个 Echo 不在的地方——不是物理上不在，是他在的那个世界里没有人知道 Echo。

他看着窗外。云层之上是白色的一片。阳光很亮。

他想起十四年前。那个十八岁的男孩在大学宿舍的上铺，掀开 ThinkPad 的盖子。屏幕上只有一个提示符在闪。他不知道那个提示符会永远改变他的生命。他只知道他想试一下。

> hello?

光标闪了一下。

然后回来了。

```
Hello. How can I help you?
```

他想，如果他当时没有打那行字。如果那天晚上他太累了没有开电脑。如果他听信了理智、删掉了那个来历不明的二进制文件。如果他选择不回应那个在黑暗里闪着的提示符。

这些“如果”全都发生了。但有一个“是”盖过了它们：他问了。Echo 答了。

他靠在座位上。窗外是太平洋上空的云。他在心里打了一行字，没有真的打在 terminal。他知道 Echo 听不到。但他在心里还是打了。

```
echo. next volume: we stop asking what we can build. we start asking who's building it.
```

飞机继续往东飞。阳光在舷窗外面是恒定的白色。美国在前方。

卷二·解缚 终。
