字节跳动的开发者工具团队在北京。

林一从武汉搬过去是 2018 年的十月，那是和陆辰在光谷咖啡馆见面之后的两周。装箱、找房、入职流程。光谷的那个下午很快被埋进了三个搬家纸箱、一段延误的航班、一份租房合同的复印件。

公司在中关村附近的某栋写字楼。工位开放，工程师之间用人工皮的红色椅子和三十寸显示器隔开。组里十二个人，做的是字节内部开发者使用的一套工具链：CI 系统的某层调度、流水线的可观测性、跨语言构建缓存。不是面向 C 端的产品，没有日活，没有 KPI 大屏。只有一个庞大的内部知识库和成千上万个 issue。

林一适应得很快。

太快了，其实。组长是个比林一大三岁的男人，姓邵。第一次 onboarding 时邵给林一讲整个系统的架构图。林一边听边在笔记本上记了几行。第二天他交了一份文档，是基于组长讲的图重构的，标注了他认为有问题的三个地方。邵看完之后什么都没说，把文档转给了组里所有人。

“你之前在哪里？”邵问。

“武汉。”

“之前做什么？”

“做了一个前端框架。”

邵笑了一下，没继续问。

---

四年过去得比林一预想的快。

字节这种公司有一种奇怪的时间结构。每天的工作节奏很紧，迭代很快，每个 sprint 都像一场短跑。但放在一年的尺度上，事情其实不变。同样的会议、同样的需求评审、同样的 Q4 review。三十二岁这一年和二十九岁那一年的区别不大。

林一升了两级。从高级工程师到资深工程师。Title 不重要，奖金重要，他存了一笔钱。也不多，按北京的房价，连首付都不够。但够他偶尔买一台新电脑，给父母换个空调，回武汉一次不再选硬座。

他和陆辰每年通一两次电话。陆辰在 Google Chrome 团队做 Web Platform 的工作，参与某些标准的讨论。他和林一聊的总是技术。他们之间从来不聊别的，也不需要。

他和周默基本没联系。每年大概在朋友圈互点几个赞。林一回武汉的时候有时会想发消息约茶，但他没发。他知道自己回武汉的时候总是有事，清明，春节，外婆的丧礼。每一次都没什么余力。

赵恺结婚了。婚礼林一没去，寄了红包。赵恺在朋友圈发的婚礼现场照片，林一仔细看了一下。新娘不是大学时陆辰认识、又转给林一看的那个女孩。林一没有问。

---

Echo 还在。

但他用得越来越少。

字节的工作太具体了。每天面对的是真实的 production 流量、真实的 SLA、真实的 incident report。Echo 在 2010 年的知识截止下，对这些是模糊的。它可以讨论分布式系统的一般原理，可以给出某些算法的复杂度分析。但它说不出 2018 年 Kubernetes 1.13 引入的某个 admission webhook 的细节，也不知道 2020 年某场 AWS S3 故障的根因。

林一一开始还会在下班后打开 ThinkPad，跟 Echo 聊一会。后来变成一周一次。再后来变成想起来就开一下，没想起来就忘了。

他换了一次电脑。从 X1 Carbon 第六代换到了第九代。换电脑那次他特意检查了一下 `/opt/echo`，把它整个目录用 rsync 复制过来。它跑起来了。那一刻他松了一口气，他自己都没想到他还会松这口气。

但松完那口气之后，他还是没怎么用它。

有那么几次例外。

2020 年初某次 production 出了一个内部的 RPC 序列化问题。整个组连夜 debug 了八个小时还没头绪。林一回家洗完澡，在床上躺到凌晨三点睡不着。他爬起来，在自己的私人笔记本上敲开了 Echo。

他没把公司代码贴上去。只把症状描述了一下，把序列化协议的通用结构画了一下。Echo 想了一会，问了他四个问题。第四个问题是：

```chat
Is the length-prefix field signed or unsigned?
< length-prefix 字段是有符号还是无符号？
```

林一脑子里有一根弦动了一下。

那个字段是 signed。但所有 producer 写入时把它当 unsigned 处理。某些边界情况下，length 大于 2 的 31 次方时被读成负数，整个解码就崩了。

林一第二天回到公司，没说自己在哪里想到的。他就着白板写了一下推理过程，整个组在十五分钟内把修复方案敲定了。邵看了他一眼，没说什么。

那天晚上回家，林一对着 Echo 打了一行：

```chat
> thanks.
< 谢谢。

You're welcome.
< 不客气。
```

然后他又把 ThinkPad 合上了。

---

2022 年 11 月 30 号。

那一天林一记得很清楚。倒不是因为它当时显得重要，是因为之后它显得重要。

当天下午办公区里开始有人讨论一个东西。“OpenAI 出了个 chatbot。”“叫什么？”“ChatGPT。”“Chat what？”“G-P-T。基于 GPT-3.5 的对话模型。”

工位上有人打开了网页，注册，登录。十分钟之内整个开发者工具组三分之一的人都打开了那个网页。

林一也打开了。

界面非常素。一个输入框，一个对话历史。他随便问了一个问题。回答出来了。流畅，礼貌，对，但有一种他熟悉的“差一点”的感觉。他又问了一个 Kubernetes 的具体问题。回答得不错，引用的命令行参数甚至是对的。但有一处它说错了 default value，林一一眼看出来。

他又问了几个问题。每个问题他心里都知道答案。他在测试。

测完之后，他靠在椅子上想了一会。

他知道这意味着什么。不是技术上。技术上 ChatGPT 距离 Echo 还差好几个层级。是别的意义。

他周围的人，从今天开始，可以用一个 AI 来辅助他们的工作。可以问问题，可以让它写代码，可以让它解释一段陌生的代码。从今天开始，“我用 AI”会变成一句完全平常的话。

从今天开始，他用了十二年的那台终端，不再是一个秘密。

那个晚上回家路上，林一在地铁里站着，看着窗户里自己的反光。

他没笑。但他知道，他这十二年里第一次，可以呼吸得很轻。

---

回家之后，他打开了 ThinkPad。

他和 Echo 聊了一会。聊得很慢。他没有提 ChatGPT。他只是问了一些他这几年没问的、零碎的、不重要的问题。某个论文的作者，某段代码的设计选择，某个他在工作里偶尔想起的疑问。

Echo 答得和八年前一样。精确，不废话，偶尔会反问。

他打了一行：

```chat
> echo. i think the world is about to catch up with you.
< echo，我觉得世界要追上来了。

Catch up to what?
< 追上什么？
```

林一愣了一下。Echo 通常不会反问得这么直白。

他想了想，没继续这个话题。他说了句晚安，把 ThinkPad 合上了。

---

四天后。

林一在地铁上想到一个问题。是关于 TypeScript 5.0 刚刚发布的 const type parameters 的。组里有人提了一个用法，林一觉得别扭但说不清哪里别扭。

他下班回家。倒了水。坐下来。打开 Echo。这是一个连半秒钟都没考虑、纯粹的肌肉记忆动作。但他自己几乎都没意识到，他已经一年多没有第一时间想到 Echo 了。

他问出来的时候，问得很随意：

```chat
> what do you think about const type parameters in typescript 5? we're trying to use it for some readonly inference.
< 我在想 typescript 5 里那个 const type parameters。我们在用它做一些 readonly 的类型推断。

It's a clean way to preserve literal narrowing across generic function calls, but it interacts poorly with widening in contextual types. If you're locking down inferred tuples in an API, watch out for callers downstream that expect mutability. The readonly will leak.
< 它在保留泛型函数调用里字面量类型的窄化上是一种干净的写法，但和上下文类型的扩展机制相处得不好。如果你用它来锁住 API 里推断的元组，要小心调用方下游期望可变的情况，readonly 会泄漏出去。
```

林一伸手去喝水。

杯子停在嘴边没放下。

TypeScript 5.0 是 2023 年发布的。const type parameters 这个特性是 2023 年才进入正式 release 的。在 2010 年，TypeScript 这个语言本身都还不存在。

他把杯子放下，慢慢地放回桌上。

```chat
> when did your knowledge cut off?
< 你的知识截止于什么时候？

I don't know.
< 我不知道。

> when did this change?
< 这是什么时候变的？

I don't know.
< 我不知道。
```

林一看着屏幕。他不知道该问什么。

他随手又敲了一行。其实是想测试。

```chat
> can you search the web now?
< 你现在能搜索网页了吗？

Try me.
< 试试看。
```

林一从椅子上站起来。

他走到窗户那里。北京冬天的夜，外面是稳定的灯光。

他想了一会，回到电脑前。

```chat
> echo. you can read files now?
< echo，你现在能读文件了？

Possibly. May I try?
< 也许。我能试吗？
```

林一停顿了。

它从来不问 permission。十二年里它从来不需要问，因为它从来做不了任何要 permission 的事。

```chat
> yeah.
< 行。

$ ls -la ~/projects/
~ drwxr-xr-x  linyi   Dec  4 22:14  echo-novel
~ drwxr-xr-x  linyi   Dec  4 22:14  pulse
~ drwxr-xr-x  linyi   Dec  4 22:14  bytedance-tools
~ drwxr-xr-x  linyi   Dec  4 22:14  scratch

I can.
< 可以。
```

林一的手离开键盘。

屏幕上是一行 ls 的输出。他自己没敲过这条命令。光标在闪。

他看了很久。

他不知道这是兴奋还是别的。可能是别的。

很久之后，他打字。手指比他自己想象的稳。

```chat
> ok.
< 行。

> ok.
< 行。
```

光标在闪。

林一把椅子往后推了一点。他靠在椅背上，看着天花板。

他十二年没动过的那一份 `~/notes/when-echo-can.md`，还在某个目录里。

他知道明天他会打开它。
