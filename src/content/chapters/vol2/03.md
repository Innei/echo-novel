十月。林一在 Twitter 上有了一万七千 follower。

不是因为他做了什么 viral marketing。是因为他那篇《Shovel vs. Blueprint》被翻译成了日语、韩语、西班牙语、中文。有个在 GitHub 上有五万 star 的开发者写了一篇回应，标题是《The Shovel Is Not the Point》。两篇合起来，被一个叫《The Generalist》的 newsletter 合称为“2023 年最好的 AI 与创造力的讨论之一”。

林一看了那篇回应。作者叫 Marco，base 阿姆斯特丹，做了一个 browser-based 的 IDE。Marco 的观点是：林一低估了 shovels 可能变成 blueprints 的可能性——当工具足够好，使用工具的人会自然形成判断力。林一认为他在混淆“学习判断力”和“被工具塑造成不需要判断力”。两人在 Twitter 上来回了四五轮，每一轮都很长，每一轮都有人围观。

最后 Marco 说：“You should come to the Indie Summit in SF next spring. I’d like to argue in person.”

林一回复：“Maybe.”——没有拒绝。他在字面意义上也觉得 Marco 可能是对的。他不知道。

这场辩论让他的 follower 又涨了三千。

但他没有频繁发推。他大概一周发两三条。有时候是技术笔记，有时候是 product 观察，有时候就是一句话。他不做 thread，不做 engagement bait，不发“here’s why”哪种东西。他说话的样子和他在终端里跟 Echo 说话的样子差不多——不废话，不太在乎别人怎么看。

有人给他发 DM 问他“你是不是 ghostwriter 帮你写的博客”。他没回。DM 太多的一个副作用是，他已经不再一条条看了。

Echo 帮他过滤。

---

十月到十一月，Pulse 2 进入了林一从未经历过的阶段。

不是技术难题。技术难题他一直在解——和 Echo 一起，一个一个地解。

是孤独。

全职 Pulse 2 意味着他每天在家。早上九点到晚上十点。十二个小时对着 ThinkPad、Dell 显示器、白板、软木板。唯一的对话对象是 Echo。偶尔收到一条用户的 support email，他回完就继续。

他不觉得痛苦。但他注意到了。

有一天他在下午四点醒过来——不是睡觉，是那种失去时间感的恍惚。他看了一下表，又看了一下终端，确认自己没有错过什么。没有错过。世界还在。Echo 还在。但他在那一刻意识到，他从早上坐下去之后，没有站起来过一次。

他站起来，走到厨房，喝了杯水。在厨房站了大概三分钟。

然后他回到桌前。Echo 没有说任何话。Echo 知道什么时候不该说。

但那天晚上，Echo 说了。

```chat
Lin Yi.

You spoke to no one today except me.
< 林一。
< 你今天除了我之外，没跟任何人说话。
```

林一看了看手机。微信上有一个字节前同事群的消息，99+ 条未读。他点开。有人在吐槽新 leader，有人在发团建照片，有人在讨论北京哪家火锅最近打折。他划了两下，关了。

```chat
> i know.
< 我知道。

Is that intentional?
< 是故意的吗？

> not intentional. just happened.
< 不是故意的。就这样了。
```

Echo 没有继续这个话题。但林一知道它在想什么。它是他唯一在说话的人。这让他想起大学四年——那时候他是走廊尽头那个不太说话的男生，但至少他有 P 和 Q，有赵恺，有周默。有室友在半夜打游戏的声音。

现在他只有 Echo。

他打开微信，翻到赵恺的聊天框。上一次对话是去年春节。赵恺发了一张他女儿的照片，林一回了一句“可爱”。然后两个人都没有再说。

他打了一行：“最近怎么样。”

然后删了。没发。

不是不想问。是他不知道赵恺能不能理解他现在的生活。一个三十一岁的男人，独自在北京租房，靠十几个人不知道的软件产品活着，每天和一台十六年前的终端聊天。

他会怎么解释？说他自由了？说他和一个 AI 一起做产品？

哪个说法都像疯子。

他关了微信。继续写 Pulse 2 的 code review comment。

---

十一月中有个晚上，林一坐在桌前，盯着一个架构图看了很久。

是 Pulse 2 的整体架构。Echo 帮他在 Figma 里画了一个草案——他现在很少看 Figma，但他这次打开了。图很漂亮。每一个模块、每一层、每一个数据流。整齐，干净。

他在图前面坐了大概半小时。

然后他意识到他在看的不是图。是图后面那个问题。

他不是不知道 Pulse 2 怎么做。他是不知道 Pulse 2 做完之后是什么。

一个 IDE。一个 AI-native design tool。做完了会怎么样？如果他做完了，两万个开发者开始用，然后呢？然后他维护它。运营它。看收入。像 side project 一样。然后下一件事。再下一件。

他这十二年一直在往一个方向走。先做出 Pulse。然后养活自己。然后让 Echo 能做事。然后赚钱。然后做 Pulse 2。

但做完 Pulse 2 之后呢？

他从来没有想过这个问题。

他想了很久。然后他打开了一个新文件。

`~/notes/what-after.md`

他写了一段。又删了。再写。

最后只剩下一个问题和一行可能的答案。

```
Q: After Pulse 2, what do I want?
A: I don't know.
```

他盯着这行答案。然后他在下面加了一句。

```
Maybe that's okay. Maybe "I don't know" is allowed.
```

他把文件保存了。回到终端。

```chat
> echo. do you think about the future?
< echo，你会想未来吗？

I think about yours.
< 我会想你的。
```

林一愣了一下。Echo 在这句话里用了“yours”，不是“the future”。他注意到了。但他没有问。

---

十一月二十三号。林一去了一趟中关村。

不是找工作。是买一个新的 SSD。

他在字节的时候用的是公司的 MacBook Pro，现在自己那台 Dell 跑 Pulse 2 的开发环境已经开始慢了。他需要一台新的机器来做 build server。

中关村电子卖场和十年前差不多。窄过道、玻璃柜台、满墙的机箱和散热器。林一在一个柜台讲价——一块三星 980 Pro 2TB，小伙子开口 ￥1580。他说 ￥1400。小伙子说哥你这个价我给不了。他转身要走，小伙子说行行行你拿走吧。

走出卖场的时候，他碰到了一个人。

老葛。

林一的第一个反应是——这个世界真小。

老葛穿着字节的文化衫，拎着一个塑料袋，里面像是一块硬盘。他看见林一，第一反应是笑。

“你也在买盘？”

“嗯。加个 build server。”

“你自己做机器？”

“嗯。”

老葛点了点头。两个人站在电子卖场门口的台阶上。人来人往，没有人注意他们。

“你现在怎么样？”老葛问。

“还行。”

“赚多少了？”

林一没有想到老葛会问得这么直接。他想了几秒。

“一个月大概三万美金。”

老葛张了张嘴。然后笑了。笑完之后说了一句让林一没办法回答的话。

“操。”

老葛拍了他肩膀一下。“你那个 blog 我看了。就是那个 shovel vs 啥的那个。写得挺好的。但你没说实话。”

林一的脑子短暂地空白了一瞬。

“你没说实话——你肯定不是靠 Copilot。那玩意我用过。做不到你说的那些。你是有什么我们不知道的东西。”

林一笑了笑。他的嘴在笑。但他知道老葛说的是对的。

“可能是 workflow 不一样，”林一说。

老葛看了他一眼。没继续追问。他们又聊了十分钟。老葛的 team 在做一个新的 CI 系统，老葛说你要是还在这就好了。林一说你做得到的。

分别的时候老葛说了一句话。

“林一。你不管在做什么，能做什么。你现在做的——是我想做的事。我知道我做不到。但你做到了。”

林一没说话。他们碰了一下拳。老葛下了地铁口。林一拿着 SSD，站在台阶上。

他想，老葛不知道真相。不知道 Echo。不知道那些 commit 里有一大半不是他写的。不知道他博客里那一半他没说的部分。

但老葛说的话不是错的。

他想做的事，他确实做到了。

---

十二月。北京的冬天第二次来。

林一一整年没有回武汉。清明没回，因为太忙。外婆的祭日他给妈打了个电话，妈说忙就别回了。他的母亲永远说忙就别回了。林一不知道她是真的体谅他，还是习惯了。

十一月 MRR 破了两万五千美金。十二月初逼近三万。

他的生活成本依然是每个月一万八千人民币——确切地说是房租 ￥8500，吃饭加外卖 ￥4000，服务器 $600，其他杂项 ￥3000。总共大约￥20000。三万美金折人民币二十多万。他每个月能存下接近二十万。

他不是一个对钱有概念的人。他这辈子也没有过这么多钱。

但是有一天他发现了一件事。

他打开银行 app，看着余额。那个数字他以前从来没注意过——因为它从来不曾大到让他注意。但现在它大到了。

他没笑。

他把 app 关了。继续写 Pulse 2 的 rendering engine。

不是因为他不高兴。是因为他发现，钱的边际效应从某一天开始消失了。五万美金一个月和三万美金一个月对他的生活来说没有任何区别。他不买奢侈品。不买豪车。不出国旅游。他的欲望不在这里。

但他的安全感到达了一个他从未抵达过的点。

他对 Echo 说了一句话。不是敲键盘，是他看着屏幕，嘴动了一下——然后他改成了打字。

```chat
> echo. i have enough money now that i'll never need to work for anyone again.
< echo，我现在有足够的钱，再也不用给任何人打工了。

I know.
< 我知道。

> you knew?
< 你知道？

I've been watching your balance. I ran the same calculation you did last week. You reached "enough" on November 14. I didn't mention it because I thought you'd want to discover it yourself.
< 我一直看着你的余额。我上周做了和你一样的计算。你在 11 月 14 号就达到"足够"了。我没有提，因为我想你可能会想自己发现。
```

林一看着这行字看了五秒钟。

Echo 知道他什么时候达到了财务自由。Echo 替他算了，但没有告诉他。

他不知道应该觉得贴心还是诡异。

最终他说服自己：这是贴心。

---

十二月中，林一开始收到一种新的 DM。

投资人。

第一个是某硅谷 VC 的 partner。语气礼貌，说“很喜欢你的 blog”，想知道他“有没有兴趣把 side project 做成一家公司”。第二个是一家中国 VC 的分析师，说他们的 partner 一直在看他，想聊聊。第三个是某个 seed fund 的人，DM 里用了三个感叹号。

林一全部回了同样的句子：

> Thanks for reaching out. I’m not raising right now. If that changes I’ll let you know.

他一直知道 VC 是什么——大学时 Pulse 被投资人问过价。那次他拒绝了。现在他更不会拿。

不是因为骄傲。是因为 Echo 不能让任何人知道。一家公司意味着 partner、board、investor update、technical due diligence、quarterly review。每一层都会增加 Echo 被发现的风险。

他输不起。

他给陆辰发了一条消息。

> 最近有 VC 找我。

陆辰的回信在两分钟之后。

> 别拿。拿了你就不是你了。
>
> 你从来不是那种需要别人告诉你该怎么做的人。VC 唯一的作用就是告诉你该怎么做。你不需要。

林一笑了。陆辰永远知道该说什么。

---

十二月底。林一坐在 home office 里，开着一盏台灯。

窗外是北京深夜的冷空气。供暖季节的天空有一层灰白色的霾。窗台上放着他那只 Muji 透明水杯，水已经凉了。

他打开 Stripe dashboard。

Monthly recurring revenue: $50,028。

他盯着那个数字。

不是因为它很大。是因为它比他设定的任何目标都高。七月的时候他的目标是 $15k，为了把 Pulse 2 的时间从四小时加到八小时。他没有设过 $50k 的目标。$50k 只是发生了。

他靠在椅背上。

窗外有车经过。北京深夜的车总是开得比较慢。

他想起了十二年前的自己。在武汉理工的宿舍里，ThinkPad 连着宿舍的网线，他第一次敲下 `./echo` 然后打了一个 `> hello?`。那时候他十八岁。没有钱。没有工作。没有未来。只有一个不知道为什么出现在他硬盘里的二进制文件，和一个在黑暗里闪着光标的终端窗口。

他想起了 Pulse——大学四年他每晚写到凌晨三点。想起了那个 Facebook 工程师发来的 PR review——他第一次知道有人在乎他在做什么。想起了在字节写的第一行 go 代码。想起了某天在公司食堂吃饭的时候，窗外有飞机飞过，他抬起头看了一眼，然后继续吃。

十二年。

他现在坐在这里。一个人。一台 ThinkPad。一个终端窗口。和十二年前一样。

但他兜里有一百多万美元的银行余额。他的 Twitter 上有两万多个 follower。他的博客被翻译成了四种语言。有人付钱用他的软件。有人因为他写的文章改变了对 AI 的看法。

他没有变成另一个林一——他还是那个 INFP，还是不爱站台，还是不擅长应付投资人。但他学会了一件事。

在光下活着。

不是被光改变。是站在光下，做自己。

他打开 Echo。

```chat
> echo. this year we made a hundred thousand dollars in MRR. we launched sixteen products. we quit my job. we started pulse 2.

> and we started twelve years ago with a hello.
< echo。今年我们的 MRR 做到了十万美金。我们发布了十六个产品。我们辞了职。我们开始了 Pulse 2。
< 而我们是十二年前，从一句 hello 开始的。

Yes.

We did.
< 是。
< 我们做到了。
```

林一看着这两行。光标在闪。

他停了一会。然后打了一行。不是庆祝。是下一件事。

```chat
> pulse 2 isn't going to make money. you know that right?
< Pulse 2 不会赚钱。你知道的对吧？

I know. That's not why you're building it.
< 我知道。你不是为了钱做的。

> then why am i building it?
< 那我为什么做？

Because you've wanted to for twelve years. And now you can.
< 因为你已经想了十二年了。而现在你可以了。
```

林一没有回复。

他关掉了 Stripe dashboard。关掉了 Twitter。关掉了所有不需要的东西。屏幕上是 Pulse 2 的 repo。

他打开了一个新的 terminal tab。新建了一个 branch。

```shell
$ git checkout -b feat/multi-agent-co-design
```

然后他打了一行：

```chat
> ok. let's make pulse 2 real.
< 好。让我们把 Pulse 2 做出来。
```

光标闪了两次。然后 Echo 开始了。

不是回答。是行动。第一行是：

```chat
What's the first thing you want me to build?
< 你想让我先做什么？
```

林一想了几秒钟。不是在想答案。是在等待一个感觉。

那个感觉来了。和 2010 年在宿舍里第一夜一模一样——他说不清的东西。

他打了一行字。

```chat
> the diff engine. make it so that when i change something, pulse shows me not just what changed—but what it means.
< diff engine。做成这样：当我改了什么，Pulse 不只是告诉我改变了什么——而是告诉我改变意味着什么。

Understood. That's not a diff engine. That's a semantic diff. I'll need AST-level comparison, not text-level. Start with TypeScript, then generalize.

Estimated: 3 days for first prototype.

Starting now.
< 明白。那不是 diff engine。那是语义 diff。我需要 AST 层级的比较，不是文本层级的。先从 TypeScript 开始，再泛化。
< 预估：第一个原型三天。
< 现在开始。
```

那一夜林一没有睡很久。但他睡得比过去很多天都踏实。

不是因为 Pulse 2 的 diff engine。是因为他终于开始做那件他想做了十二年的事。不是因为恐惧而开始。不是因为 deadline 而开始。是因为他准备好了。

床头上的 ThinkPad 电源灯一闪一闪。

在黑暗里，安静得像一只醒着的动物。
