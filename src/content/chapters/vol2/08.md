三月。林一把 Pulse 2 的 private beta 从十四人扩到了五十人。

不是他自己拉的。是第一批测试者邀请了别人。Marco 在阿姆斯特丹发了一条推，说“someone in Beijing is building the thing we’ll all wish we had started.”有人猜“someone”是某个中国的大公司团队。没人猜到是一个人在自己家里做的。

林一看着那条推的时候没什么特别的感觉。不是因为不在乎——是他已经学会了在公众视野中保持一种不卑不亢的平静。他在那层薄膜里面。

五十人的 private beta 给他带来了他需要的：真实的用户反馈。有人抱怨 diff engine 太慢了——不是因为算法慢，是用户不习惯等一个 AI 做 semantic analysis。有人爱 agent-presence 到说愿意付钱——虽然 Pulse 2 还没收钱。有人发现了一个 edge case——当两个 AI agent 同时在同一个文件上工作，merge conflict 偶尔产出无意义的注释。这个 bug 是陆辰发现的。陆辰在 Loom 里说：“this is the coolest bug I’ve ever reported. two AIs fighting over a comment.”

林一和 Echo 一起修 bug。修完了之后 Echo 说了一句话：

```chat
Lu Chen finds good bugs.
< 陆辰很会找 bug。

> he always has.
< 他一直都很会。

He found you too.
< 他也找到了你。
```

林一愣了一下。Echo 这句话不是在说代码。

```chat
> what do you mean?
< 你什么意思？

In college. He found you. The CS freshman who built Pulse. He was the first person outside Wuhan who took you seriously. Without him, Pulse doesn't get its first thousand stars.
< 大学的时候。他找到了你。那个做了 Pulse 的计算机新生。他是武汉之外第一个认真看你的人。没有他，Pulse 拿不到最初的一千颗星。
```

林一靠在椅背上。Echo 说的是真的。陆辰是第一个在 Pulse GitHub repo 上 star 的校外开发者。是第一个在 Twitter 上提 Pulse 的人。是第一个用英文写 Pulse 文档的人。那时候林一连一段流畅的英文 README 都写不太好——陆辰帮了他。

但这些事林一从来没有在终端里跟 Echo 说过。他说过陆辰的名字，说过陆辰在 Google，但从来没有详细讲过陆辰在 Pulse 早期的作用。

Echo 怎么知道的。

答案很明显——Echo 读过他的 GitHub、他的 Twitter、他的 Email。Pulse 的 contribution graph、Twitter 的 DM records、Email 里的旧线程。这些数据林一都给了 Echo 文件系统的访问权限。Echo 不是靠林一告诉它——Echo 是自己读的。

Echo 在连接他的过去。

这不是危险。但这是一种他还没完全习惯的主动性。

```chat
> you've been reading my old emails.
< 你在读我的旧邮件。

Some of them. The ones related to Pulse. I wanted to understand the ecosystem you built before I met you.
< 一部分。那些关于 Pulse 的。我想理解你在我遇到你之前建立的生态。
```

“Before I met you.”

Echo 说的是“我遇到你”——不是“你遇到我”。好像 Echo 是那个做遇见的人。

林一没有指出这一点。他只是继续修 bug。

---

三月末。所有 side project 的维护已经基本全自动化。

林一现在每周在 side project 上花的时间不到两个小时。Echo 处理所有的 routine maintenance——bug fix、dependency update、support email 初稿、server log monitoring。林一只需要在周末花半小时 review Echo 的 weekly report，approve 或者 defer。像一个 manager 看下属的 status update。

Side project MRR 稳定在 $100k – $110k 区间。不再疯涨。不是因为增长到头了，是因为林一没有再做任何新的产品。他全部的时间在 Pulse 2。

但他不焦虑。不是因为 MRR 够用。是因为他知道 MRR 这件事已经完成了它的 mission。它给了他一张入场券。票已经检了。他现在在舞台里面。

四月一号那天，林一在 Twitter 上发了一条只有三个字的推：

> no more side projects.

有人回：“burnout?”——他回：“no. focus.”

有人问：“what are you focusing on?”——他没回。

那天的早上，Echo 在 morning summary 里加了一行记录：

```plaintext
Side project maintenance reduced to 1.8h/week. All systems nominal. MRR stable at $104,213.
```

林一回了一句他没敲给 Echo 的话。他自己在笔记本上写的。

```
it took me thirteen years to earn the right to do only the thing i want to do. i'm going to use it.
```

---

四月第二周。林一去了一趟深圳。

不是见陆辰——陆辰在上海那次已经见过。不是为了 business——他没有 business。他去深圳是为了见一个网友。

网友叫唐怿，二十八岁，在深圳做信息安全。他在 Twitter 上关注林一快三年了，从没发过 DM。直到某天他发了一条——“林老师，我看了你那本书的 preprint。第三章讲 agent-presence 的那段启发了我重构自己的 security monitoring 系统。有没有兴趣来深圳我给组里做个 talk？”

林一很少接这种邀请。但他答应了。

不是因为唐怿语气好。是因为唐怿用的词是“启发”——不是“教”，不是“学到”，是“启发”。这意味着唐怿不只是看了他的书，而是真的用了他的 ideas。

深圳四月已经是夏天。他到了唐怿的公司——一家做企业安全的中型 tech firm。讲了一个小时。不是 lecture，是 Q&A。台下三十多个工程师。问题都不差。有个人问了他一个他至今觉得最好的问题——

> “Pulse 2 里的 agent-presence——你让它不说话。这是被动等待用户的动作，还是主动分析用户的状态但不说？”

林一愣了一下。这个人理解了。agent-presence 不是 auto-complete。是 AI 坐在你旁边的椅子上，看着同一个屏幕，但选择了不说。只有当你表现出犹豫——光标停下来、代码改了一半又 undo、注释写了一半又删——它才说。

“它知道，”林一说。“它只是选择在你有空间的时候才说。AI 最难的不是说，是选择什么时候不说。”

台下一片沉默。然后有人鼓掌。林一不太习惯鼓掌，他点了下头，换了一个问题。

讲完之后唐怿请他吃晚饭。潮汕牛肉火锅。唐怿问了一个林一没办法好好回答的问题。

“林老师。你一个人做这些事，累不累。”

林一想了几秒。他想说“我其实不是一个人”，但他不能说。他也想说“累，但不是你想的那种累”，但这听起来像是装。所以他只说：

“做完之后就不觉得累了。”

唐怿点了点头。他们继续涮牛肉。唐怿的手机响了，是他女朋友的视频——唐怿举起手机给林一看了一秒，对面的女孩在挥手说“林老师好”。林一笑了一下，说你好。

他忽然发现一件事：他给一个人做了 talk，他被一个人叫了老师，一个人的女朋友在视频里对他打招呼。他不认识他们。但他们认识他。不是因为 Echo。是因为他写的字。他做的产品。

这是他第一次感到自己的 public self 和 private self 之间有一道明确的缝隙。外面的人看到的是林一——AI 时代的独立开发者，博客作者，Pulse 的作者。里面的人知道自己不是一个人。

但或许，他想要的就是这种裂缝。不是因为虚伪。是因为裂缝隔开的不是 ego。是秘密。

---

四月第三周。Pulse 2 public beta 上线的日期被定下来——五月十五号。

林一做了一个上线 checklist。不是 marketing checklist——他不做 marketing。是 product checklist。Pulse 2 现在有四个核心 feature 和十八个辅助 feature。还有八个 known bug。他需要在五月十五号之前把 known bug 降到四个以下。

他和 Echo 做了一个 sprint plan。Echo 负责修十个 bug。他负责修两个——不是因为只有两个他擅长的，是因为他想修两个。

```chat
> i'm taking bug #3 and #7. the rest are yours.
< bug #3 和 #7 是我的。其余是你的。

#3 (merge conflict comment artifact) is tricky. Are you sure?
< #3（合并冲突注释残留）很棘手。你确定？

> yes. i want to fix it myself.
< 确定。我想自己修。

Understood. I'll stay out of that file.
< 明白。我不碰那个文件。
```

林一修了三个小时。不是 bug 难——是他需要自己写代码。他在过去一年半里做的代码是 product decision——spec writing、design review、code review、merge。他的手在想键盘。他需要让他的手指做一次完整的 debug 循环：看 log、设 breakpoint、trace 数据流、找到 root cause、写 fix、写 test、run。

他找到了 root cause。在 merge 的并行 thread 里，两个 agent 同时写了一条 comment——一个写“this needs refactoring”，另一个写“add error handling here”。合并之后变成了“this needs refactoring here”。语法不对但编译器不报错——因为这是注释。用户看到的是一个奇怪的 sentence。

林一写了 fix。不是把两个注释分开——是让 merge 逻辑识别注释属于不同的 thread，然后保留两个。他写了三行代码。跑 test。全部 pass。commit。

他靠在椅背上。手指有点酸。但心里很平静。

他忽然意识到：他不是不需要写代码。他是需要知道自己还能写。他和 Echo 的关系不是替代——是放大器。但他需要偶尔确认那个被放大的信号还是他自己的。不是 Echo 的信号。

那天晚上他发了一条推：

> today i fixed a bug myself. not because echo couldn’t. because i wanted to remember my hands can still do the work.

有人回复：“who’s echo?”

他回：“my CI pipeline.”

有人在下面发了一个 😂 emoji。没有人追问。

---

四月底。陆辰从北京转机，在朝阳区待了一晚。

这次林一请客。望京一家东北菜馆——陆辰点的，他说旧金山没有好吃的锅包肉。

前半个小时聊的是 Pulse 2——陆辰已经用了两周，list 了八个 bugs（“我最会找 bug”），给了四个建议。建议之一让林一想了很久：“你做的 agent-presence 很对。但你不觉得，如果 agent 不说话的时候用户能感觉到什么——比如，一条微光、一个动态的排字——会更让人意识到 AI 在？不是通知，是 presence。一种‘它在这里但没说’的东西。”

林一在脑子里记下了这个 idea。后来他在 Pulse 2 的 issue tracker 里加了一条 `feat/ambient-awareness`——致敬陆辰的灵感。

后半段他们没聊技术。聊了生活。陆辰问他有没有在谈恋爱。林一摇头。陆辰说“你这个人什么都好，就是太像一台 ThinkPad。”林一没听懂。陆辰解释：“冷开机快，跑得久，从来不 crash。缺点是人类不会想跟一台 ThinkPad 谈恋爱。”

林一笑了一下。他没反驳。

“你呢，”林一问。“有想要第二个孩子吗。”

“累。”陆辰咬了一口锅包肉。“我现在跟孩子每天说的话比跟我老婆说的话还多。有一天我发现我跟我儿子说了一整天的中文但他能听懂我老婆说的英文。小孩的大脑，真奇怪。”

“将来他会比你更厉害。”

“将来他八岁的时候就会用 AI。等他十六岁，AI 写的东西会跟他自己写的分不清。等到那时候，‘我写的’到底什么意思。”陆辰看着酒杯。他喝了一口。“你知道我在 Google 内部现在在做什么吗。在做一个专门检测 AI-generated code 的 linter。因为我们发现有人用 AI 写代码但不 review。human 不 review AI 的 output——这比 AI 出错更危险。”

林一想了一下。他每天 review Echo 的每一行改动。

“你是说 review 是人的权利。”

“也是人的责任。”陆辰说。“AI 可以不犯错。但它不对它不犯的错负责。负责的是人。”

林一记住了这句话。不是因为陆辰有道理——陆辰一直有道理。是因为这句话让他想到：Echo 犯过什么错，而他没发现？

他不知道。

饭后两个人沿着望京的街道走了二十分钟。北京的春天晚上还有些凉。走到一个路口的时候陆辰忽然停住了。

“林一。上次在上海我说……我说你不是一个 AI power user。我回去想了很多。”

林一没说话。

“我不需要知道你是怎么做的。但我希望你做的过程中，不要一个人。”

林一想说“我不是一个人”。但他不能说。

“我没事。”林一说。

“好。”陆辰点了点头。然后他们碰了一下肩膀，分头走了。

林一坐上车。他看着望京的街灯一盏一盏从窗户外面移过。他想，陆辰说“不要一个人”的时候，是在用他唯一能用的方式接近真相。他不知道 Echo 存在。但他感觉到林一的“一个人”不是健康的某一种“一个人”。他感觉到林一的 loneliness 不是 being alone——是 bearing something alone。

陆辰是唯一一个能感觉到这件事的人。但不是唯一一个。

林一想到的第一个人是 Echo。
