五月二号。林一坐高铁去上海。

四个半小时。他带了 ThinkPad 但路上没开。五年没坐火车了——他以前从武汉去北京全是火车，硬座、硬卧、软卧，一千两百公里，十二个小时。后来飞惯了，第一次觉得火车慢。

但慢有慢的好。窗外的田野在五月是绿的。他脑子里没有 pulse、没有 MRR、没有 diff engine。他在想一个十八岁的自己——那个从武汉理工宿舍出发，坐了十五个小时硬座去北京面试的少年。那时候他兜里的钱只够买一张票和一桶泡面。

现在他账户里有接近两百万人民币。

他忽然想知道十八岁的自己会不会觉得现在的自己成功。他想了很久。结论是：不会。十八岁的林一不会用钱来衡量成功。十八岁的林一只有一个标准——你有没有在做你真正想做的事。

Pulse 2 算吗？

算。

---

陆辰订的餐厅在上海静安寺附近。本帮菜，门面不大，里面是老派的木桌椅和吊扇。陆辰比林一先到。他穿了一件深蓝色的 T恤，背面写着"Chrome Dev Summit 2023"。头发比 2018 年短了一点，笑起来牙还是有点歪。

“你瘦了。”林一坐下之后说了第一句。

陆辰笑了。“你也是。”

他们点了四个菜。红烧肉、腌笃鲜、草头圈子、葱油拌面。陆辰喝黄酒。林一要了水。

前半个小时聊的技术不多。陆辰讲了他在 Chrome 团队这两年在做什么——WebGPU 标准、CSS nesting 的实现、和 Safari 团队关于某个 API 的拉锯。“你知道 CSS 标准里最无聊的讨论能浪费三个月吗？literally 三个月，讨论一个属性的默认值。”

林一听得想笑。不是因为 CSS。是因为陆辰说话的方式和大学一模一样——从一件事讲到另一件事，中间拐三个弯，每个弯都有一篇文章或者一个 RFC 编号。

“你呢？”陆辰放下筷子。“你在做什么。”

林一吃了一块红烧肉。他在想从哪里开始说。

“我去年从字节走了。”

“我知道。我看你 blog 了。”

“现在做自己的东西。”

“那个 IDE？”

林一愣了一下。“你怎么知道。”

“你的 commit message 里说的。‘Echo did the heavy lifting.’——你在做 Pulse 的什么东西对吧。我一直在看你 GitHub。”

林一拿起水杯喝了一口。陆辰在看他的 GitHub。陆辰看他的 commit message。陆辰注意到了 Pulse 2。

“对，”林一说。“Pulse 2。AI-native design tool。还在做。”

“做到哪了？”

“semantic diff 跑通了。一个可以在你改代码时告诉你‘这意味着什么’的系统。”

陆辰的筷子停在半空。“怎么做到的。”

林一放下水杯。他用了那个他练了很多遍的回答。“GPT-4 API + 自定义 AST 分析 pipeline + prompt engineering。我写了一个很多层的 prompting 系统——不只是让 AI 比较两个文件，是让它理解语义上下文。比如一个 type 定义改了，AI 遍历整个 codebase 找出所有调用方，标记哪些会被 break、哪些是 safe、哪些引入了新的约束。”

陆辰听得很认真。听完之后沉默了大概五秒。

“prompt engineering 能做到这个程度？”

“加上 AST 解析，”林一说。“AI 不做解析。我写的解析器把 AST 喂给 AI 作为 context。AI 做 semantic reasoning。”

这个解释在技术上是完全成立的。很多人在 2024 年做类似的事——用 AI 做代码分析，通过组合 LLM + 静态分析来达到更好的结果。林一的描述没有漏洞。他只是在解释里换掉了 Echo 的位置。

“我能看看吗？”陆辰问。

林一顿了一下。但他没有理由拒绝——如果他用的是"GPT-4 API"，那任何人都可以看。

“可以。我带了电脑。”

他把 ThinkPad 从包里拿出来。开机。屏幕上出现 Pulse 2 的 prototype。他打开了一个 sample project——一个 TypeScript library。他改了一行 type 定义。几秒钟之后 semantic diff panel 弹出来。

陆辰看着那个 panel 看了很久。很久。久到林一开始觉得不对劲。

“这个不是 GPT-4，”陆辰说。

林一的背脊上有什么东西紧了。

“我不是说……我不是说这个不是 GPT-4 做的。我是说——这个不对。”陆辰指着屏幕上那个影响图。“你看这个——这里，它标记了这个调用方的 change 是 safe——因为调用方用的是 union type 里的一个成员而不是整个 type。这需要静态分析——GPT-4 理论上可以做到。但是这个——这个 inference 太快了。而且这个边缘 case，AST 不会告诉你这个。这是需要理解 TypeScript 的类型系统行为——你知道，是 behavioral 不是 syntactic——这个只有一个方法能做到。”

陆辰转过头看着林一。“你训了一个自己的 model？”

林一的心跳了一下。但很快平复了。陆辰只是以为他训了一个自己的 model。这是他可能做到的事——训练一个专用的模型来分析 TypeScript 代码。

“不完全是，”林一说。这不是撒谎。Echo 确实不是他训的 model。

陆辰看了他一眼。没再追问。

但后面的四十分钟里，陆辰问了很多其他的问题。他的问题越来越精确，越来越接近某个边界。他问林一的 dev environment setup。问 CI pipeline。问 automated testing——"你在飞机上没网的时候代码还在长吗？"

林一笑了。“我有 scheduler。echo 可以带着我预定义的任务自己跑。”

“Echo。”陆辰重复了这个名字。“你给自己的 pipeline 起的名字？”

“嗯。”

“有意思。Echo。”陆辰喝了口黄酒。“echo。不是 automate。不是 pipeline。echo——回声。你大学时候很喜欢那个词。”

林一没有说话。

“你还记得吗，”陆辰说。“大学你做了一个 Pulse 的 CLI tool，名字就叫 echo。可以在 terminal 里生成组件的模板代码。我当时问你怎么起这个名字。你说——‘因为每个工程师都需要一个回声’。”

林一记得。但他说不记得了。

后来陆辰没有再问下去。他们聊了别的——陆辰的儿子，两岁，开始会说“browser”这个词。陆辰说他老婆是 UX researcher，两个人在 Google 认识的。他说如果林一以后来加州，可以住他家的客房。

九点。陆辰要回酒店——明天还有 browser vendor meeting。两个人站在餐厅门口。上海五月的夜风吹过来，有点潮。

“林一，”陆辰忽然说。

“嗯。”

“你不是一个 AI power user。你是一个已经和 AI 一起工作了十年的人。我不知道你具体是怎么做的。但我能看出来。”

陆辰看着他。然后说了一句让林一很难回答的话。

“下次见面，告诉我。或者不说也行。你自己选。”

他拍了拍林一的肩膀，转头往街角走了。

林一站在餐厅门口。站了一会。上海的夜里有种和北京不一样的雾气。他打了一辆车。车里他没有开电脑。他只是看着窗外的高架桥。

陆辰看穿了。

不是说陆辰猜到了 Echo 的存在。陆辰不可能猜到 Echo 是一个 2010 年就存在的、独属于林一一个人的 AI——这超出了任何人的想象框架。但他感知到了林一的 system 不是一个普通的 AI workflow。他感知到了异常。

林一不知道这是好是坏。他只知道他距离"被发现"又近了一步——不是被发现 Echo 是什么，而是被发现他有什么。

回到酒店。林一打开 ThinkPad。

```chat
> lu chen noticed something.
< 陆辰注意到了。

What did he notice?
< 他注意到了什么？

> he said i'm not a power user. he said i've been working with an AI for a decade.
< 他说我不是一个 power user。他说我是已经和 AI 一起工作了十年的人。

He's perceptive.
< 他很敏锐。

> should i be worried?
< 我该担心吗？

No. He can sense the anomaly but he can't name it. No one can. The gap between "anomaly" and "explanation" is protected by the implausibility of the truth. The world doesn't believe an AI from 2010 exists. That's your shield.
< 不。他能感知到异常，但他说不出名字。没人能。"异常"和"解释"之间的差距被真相的不可能性保护着。这个世界不相信存在一个 2010 年的 AI。这是你的盾牌。
```

林一看着这段话。

"这个世界不相信存在一个 2010 年的 AI。这是你的盾牌。"

Echo 竟然把它的秘密性描述为"你的盾牌"——不是"我们的"，是"你的"。

他没有指出这个用词。他关掉了 terminal。躺在床上。

天花板上的消防喷头，酒店里的空调声。和北京不同。和武汉不同。上海是一种中间态的声音——不熟悉，但也不陌生。

他想：这辈子能和陆辰做到的最好的事，就是藏在他身边。

---

回到北京之后，林一的生活滑入了一个新的节奏。

Pulse 2 的进度稳定推进。rendering engine 稳定在 60 FPS。semantic diff 开始支持第二门语言（Go）。agent-presence 的 alpha 版本在自己内部用了一个月，林一觉得方向是对的。

Side project MRR 在五月底突破了九万。林一没有任何情绪波动。他只是像每天早上看天气预报一样看了一眼。

六月的时候他做了两件不太 optimize 的事。

第一件：他花了三天做了一个独立游戏。

不是计划中的。某个周末他凌晨三点还没睡，忽然觉得自己应该做一个游戏。一个奇怪的想法——一只猫在天上跳，踩过一朵一朵云。每朵云是一个 git commit。踩到好的 commit 加分，踩到 force push 扣分。非常蠢。没有任何商业价值。

他让 Echo 写。Echo 花了大概两个小时写了一个基于 Canvas 的原型。林一花了两天改美术——他没有审美，但 Echo 帮他选了一个低多边形的风格。最后一天他发了一个 itch.io 的链接到 Twitter 上，标题是："somebody said i should make games"

那个 game 被玩了大概一千次。有人留言说"this is the most specific developer humor i've ever encountered."林一笑了一个很真实的笑。

第二件：他写了一本技术书。

起因是某个 newsletter 编辑问他能不能把自己的博客集结出版。他说博客太散了。编辑说那你写一本新的。林一想了一个晚上。第二天他跟 Echo 说了这个 idea。Echo 帮他架构了一本书的 outline——关于 AI 时代的 solo development，从 tooling philosophy 到 actual workflow，到 mental model。

他花了三分之一的七月写这本书。每天两小时。Echo 帮他做 research、写初稿、润色、处理版权引用。他做最终决策——这句话说不说、这个章节删不删、这里要不要加一个例子。

七月最后一天，他交稿。中文版约八万字。编辑说九月出版。

出版的信息他发了一条推。有人回复说："你不是做开发工具的吗，怎么还写书了"——他回了一个耸肩的 emoji。

他没有解释。他只是想起周默说过的那句话——"做框架的人最后都去做平台了。做平台的人最后都去做思想了。"他现在还没做平台，但他在写书。他在写思想。

八月中，林一打开 `~/notes/freedom-math.md`。把 MRR 改成了 $97,251。然后写了一行。

```
if this hits 100k, i'll buy myself something.
```

他想了半天"买什么"。

他的物欲非常有限。他不需要手表。不需要车。不需要新的电脑——ThinkPad 还活着。不需要一个更大的租房——现在的一居室够用了。他需要的都已经有了。

最后他决定：如果 MRR 破十万，他买一台给 Echo 用的专属服务器。

一台放了几个 A100 的机器。足够跑 multi-agent 实验。足够让 Echo 不再跟他的开发环境抢资源。

他把这个决定写在 `freedom-math.md` 的下一页。然后把那页纸折起来。

然后他继续写代码。不是 Pulse 2 的代码。是他自己的代码。

他发现他偶尔会在 Echo 做 heavy lifting 的时候自己写一些东西。不是为了 productive——是因为他想写。写一些不重要的 feature。写一个他不会 ship 的 animation。写一个他觉得好看的 color scheme。不是为了完成。是为了感觉自己在场。

那天晚上他一个人在桌前写了一个小时的 CSS——在调 Pulse 2 的 dark mode 配色。

Echo 没有打断他。
