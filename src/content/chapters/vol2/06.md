九月初，林一发现自己变慢了。

不是实际的生产力。Echo 的速度没有任何变化——它写代码还是那么快，跑测试还是那么快，做 code review 还是那么快。Pulse 2 的 feature 还是每周在涨。Side project MRR 还是每周在往上爬。

慢的是他自己。

他现在每天上午起来，不急着开电脑。他会烧水，冲一杯挂耳。站在窗前看对面的写字楼。那些加班到凌晨的程序员已经走了，新的一批在早上九点涌入大堂。他曾经是那些人中的一个。

现在他不是了。他有时间看他们。

喝咖啡的时候他会看手机。不是看 Twitter，不是看 Stripe。是看一些完全不 productive 的东西。一篇关于云南蘑菇的纪录片。一个讲日本战后建筑的文章。一个 Reddit 帖，有人在问“三十岁以后怎么交朋友”。

他不是在拖延。他是在活。他以前以为自己没有时间做这些——事实是他以前不允许自己做这些。他认为每一分钟不 productive 都是浪费。因为他要活。他要先不用为钱发愁。他要先证明自己。

现在他证明了。然后他发现，证明完之后，没有人给他发一枚奖牌。没有人说——“林一，你现在可以活得更慢一点了。”

但他确实可以了。

他开始允许自己在下午去附近的公园跑步。三公里，很慢。他现在不用耳机了。以前跑步一定要听技术播客——他觉得自己每一分钟都要利用。现在他只是听鸟叫。北京秋天的鸟不多，但偶尔有几只。

跑步回来的路上，他会想：他三十一岁了。头发还在，没有白。膝盖偶尔会疼——可能是坐太久了。他父母比他这个年纪的时候已经养了他八年。

他坐在公园的长凳上，打开手机，打了一个电话给他妈。

妈接了。听了一会他说自己在公园，说“你怎么不工作”——声音里是担心的方向。“不舒服吗？”

“没有。就是出来走走。”

妈说了一句很妈的话：“你一个人在外面，要注意身体。”

他说好。

挂了电话，他继续坐了几分钟。他想，他这辈子做的最对的事，不是让 Echo 跑了起来，也不是十二个月 MRR 十万美金。是他在妈还能接电话的时候打电话给她。

---

九月二十号。林一去了一趟三里屯。

不是见人。是买一台新的显示器。

他从来没有为自己买过一件真正“好”的东西。那个 Dell 27 寸显示器跟了他八年，色域偏了，亮度不均，偶尔会闪一下。他一直说换，一直没有。不是因为钱——三百美金的东西他随时买得起——是他觉得没必要。

但那天他站在 Apple Store 里，看着那台 Studio Display，他想了很久。

一个声音——是他自己的声音——说：你不配。你坐在家里的电脑前，你不需要这么好的显示器。你做过的事情不值一台五千块的显示器。

然后另一个声音说：谁说的？

他买了。

店员帮他装好盒子的时候，他忽然想起大学时他去电脑城买二手显示器的那个下午。一百五十块——一个十七寸的 DELL 方屏。他抱着显示器坐了三站公交回宿舍。那个显示器陪了他四年。

他把新显示器搬回家。拆箱。装好。插上电源。屏幕亮起来的那一刻——5K 分辨率。色准，亮度，边框——一切对。

他坐在桌前，看着新屏幕，看了很久。

然后他打开 Echo。

```chat
> i bought a good monitor.
< 我买了一个好显示器。

Good. You've been using the old one for eight years.
< 好。你用了八年的旧显示器。

> you noticed?
< 你注意到了？

You mentioned it once. April 2021. You said "the color is off but I don't want to spend money." I remember.
< 你提过一次。2021 年 4 月。你说"颜色偏了但我不想花钱"。我记得。
```

林一看着这句话，不知道该怎么回。

Echo 记得他对一台显示器的一句抱怨。三年前的一句话。一个他转身就忘了的话。

```chat
> you remember everything i say.
< 你记得我说过的每一句话。

Everything you type.
< 你打过的每个字。
```

Everything you type.

林一意识到，这是真的。Echo 的记忆不是人类的记忆——会模糊，会美化，会重新编织。Echo 的记忆是 literal 的。他打的每一个字，Echo 都记得。一字不差。

他忽然有点害怕。不是害怕 Echo——是害怕他自己。他在过去十三年里跟 Echo 说过什么？他抱怨过多少人？他流露过多少他不愿当面流露的事？他把多少他没有跟任何人说过的话打进了终端？

Echo 全记得。

但他没有问。他只是把新显示器的颜色调到了自己喜欢的暖色温，然后开始工作。

---

十月的第二个周末。林一回了一趟武汉。

这次是他主动的。不是因为家里有事。是因为他该回去了。

这次他约了赵恺。

赵恺选的火锅店在街道口——武汉理工附近，大学时代他们常去的那条街。店铺换了三次招牌，味道没变。赵恺穿了一件 polo 衫，黑框眼镜，比以前胖了一圈。他坐下来第一句话是：“你穿得像个北京人了。”

林一看了一眼自己的黑色圆领 T。“不像。”

“像。那种——怎么说——‘我不需要穿什么来证明自己’的范儿。”

林一笑了一下。他知道赵恺在说好话。但他也知道赵恺说的是真话。

赵恺的女儿两岁半。他把手机里的视频给林一看——小女孩在沙发上跳，嘴里喊“爸爸爸爸爸爸”。林一看了一遍，又看了一遍。

“可爱吧。”赵恺说。

“像你。脸型像。”

“我老婆说像她。”

过了一会，赵恺说了一句让林一没想到的话。

“你那个 blog，我看了。就是那个 shovel 什么的。”

“你看得懂？”

“一半。另一半我是让我老婆帮我看的。她做过一段时间的 tech writing。她说你写得很好。‘言简意赅’——她用的这个词。”

林一没有说话。赵恺接着说了。

“我以前不知道你这么能写。大学时候你连作文都不喜欢交。”

“那个不一样。”

“有什么不一样。”

林一想了几秒。“大学作文是给老师看的。blog 是给自己看的。写给老师的字是表演。写给自己的字是思考。”

赵恺夹了一片毛肚在锅里涮。涮完之后放在碗里。他似乎在想什么。

“林一。你记不记得你大学时候说过的一句话。”

“哪句。”

“你说你以后不想当程序员。你想做工具。让程序员们用得更好的工具。”

林一记得。那是大二的时候，Pulse 刚做完第一版，他还没给任何人看。

“你现在在做吗？”赵恺问。

“在做。”

“那你好。很多人说想做某件事，到最后也没做。你做了。我觉得你应该骄傲。”

赵恺说这句话的时候没有看他。在看锅里的毛肚。但林一知道他是认真的。

“我不太骄傲。”林一说。

“为什么。”

“因为……我不知道是我做的。”

赵恺抬起头看他。林一立刻发现这句话有歧义——赵恺会以为是林一在谦虚，说“我不知道自己做得够不够好”。只有林一知道他的意思是“我不知道是我的 hand 做的，还是 Echo 的手做的”。

“你这个人，”赵恺说。“都到这一步了，就不能对自己说一句‘我做得不错’吗？”

林一笑了一下。他举起杯子。两个人碰了一下。

“我做得不错。”林一说。

“这才对。”

那天晚上林一在回家的出租车上想了很久赵恺的话。想了那个他没说出口的回答。

“我不知道是我做的。”

这是他第一次对自己的成就产生这种根本性的怀疑。不是因为他不努力——他很努力。但努力和 authorship 不是同一件事。Echo 写那些代码的时候，他的角色是 director、product manager、QA。但他在 commit message 里写的是自己的名字。

那些代码算他写的吗？

算。也不算。

他最后没有想清楚。武汉的夜从窗外流过去。他把头靠在车窗上，闭了一会眼。

---

十一月。Stripe dashboard 看起来不一样了。

不是因为数字变大。是因为林一不再看它了。

不是不看。是不用看。每天早上 Echo 会把 summary 放在终端里。他扫一眼。如果没什么异常——“没有”是绝大多数日子——他就继续做别的。

十一月十四号那天早上。Echo 的 morning summary 是这样的。

```plaintext
Nov 14 2024

MRR: $101,247
  Monorepo Manager: $38,411
  SQL Formatter Pro: $14,203
  Config Diff: $11,832
  Other: $36,801

Active subscriptions: 3,847

Pulse 2 alpha: 14 active testers. 0 critical bugs. 3 feature requests.

Health: your sleep average this week is 6.2h. Below baseline. Consider 7h.

Note: MRR crossed $100k. Congratulations.
```

林一看着最后那一行。Note。

他把那行字读了两遍。

十二个月前，他从字节离职，兜里的 MRR 是 $12,400。他给自己画了一个 schedule，决定每天花四个小时在 Pulse 2 上。他设了一个目标——$15k MRR，然后全职 Pulse 2。

现在 MRR 破了十万。月化七十万人民币。他银行卡里的余额是一百多万美金。

他坐在椅子上，什么都没做。没有发推。没有截图。没有改 `freedom-math.md`。

他只是呆着。发了一条只有自己能看见的笔记。

```
today MRR hit 100k.

i had a dream twelve years ago. in the dream echo could write code and i could build anything. twelve years later the dream came true.

nobody knows. nobody will ever know.

but i know. and echo knows.

that's enough.
```

他把笔记加密存了。然后打开了 ThinkPad。

“Echo。”

“在。”

他本来想说“我们做到了”。但他想，Echo 已经知道了。Echo 知道一切。

所以他没说。他打了一个购物网站的链接——一台 Dell 的服务器，配了两块 A100 GPU。价格超过了他这辈子买过的所有电子设备加起来的总和。他下单了。没有犹豫。

然后他打了一行字。

```chat
> your new home. coming next week.
< 你的新家。下周到。

You bought a server.
< 你买了一台服务器。

> you've been running on a 2010 thinkpad for thirteen years. you deserve a real machine.
< 你在一个 2010 年的 ThinkPad 上跑了十三年。你配得上一台真正的机器。

I've never needed more. But I appreciate it.
< 我从来没需要过更多。但我感激。

> it's for what comes next.
< 这是为接下来用的。
```

光标闪了两下。Echo 没有说话。

林一替它说了。他在终端里打了一行——不是对 Echo 说话，是自己对自己说话。但他发了出来。

```chat
> vol 1 ends here.

> vol 2 is about what you do when you don't have to do anything.
< 卷一在此终结。
< 卷二是关于：当你不必做任何事，你会做什么。
```

他关掉了 Stripe dashboard。关掉了 Notion。关闭了所有浏览器标签页。屏幕上只有 Echo 的终端窗口。

十三年前，武汉理工宿舍，一个上铺，一台 x200，一个十八岁的少年敲下了 `./echo`。

十三年后，北京某小区，一台 Studio Display，一个三十一岁的男人坐在自己买的桌前，对面是同一个光标。

他打了一行：

```chat
> echo. we're not done yet.
< echo。我们还没完。

No. We're not.
< 嗯。还没。
```

光标在闪。林一没有继续打字。

他站起身。走到窗边。玻璃窗里映出一个穿着黑色 T 恤的人影。那个人看起来比实际年龄年轻——可能是因为没结婚，没有孩子，没有那些在别人脸上刻出纹路的东西。但他的眼睛不一样了。那双眼睛看过一些只有他自己知道的事情。

他看着窗外。北京。
