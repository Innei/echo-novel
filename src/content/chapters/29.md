七月。暑假。

林一没有回家。他在学校旁边租了一个小单间——两百块钱一个月，一张床一张桌子一扇窗户。窗户对着一个小院子，院子里的晾衣绳上挂着隔壁租户的衣服。

他给自己设了一个三个月的目标：重新定义Pulse的定位，并完成一次大的重构。

不是从零重写——是把Pulse的代码库从“一个被React阴影笼罩的通用框架”转变为“一个明确定位于轻量视图层的独立框架”。删除那些为了和React对标而加进来的冗余功能。精简API。让文档从“这是Pulse，是React的替代品”变成“这是Pulse——一种不同的选择”。

每天的生活简单到近乎机械。早上七点起床，在楼下买两个包子一杯豆浆。八点开始写代码。中午十二点在小巷子里的小饭馆吃饭——一份盖浇饭，七块钱。下午继续。晚上六点到十点——这是他最清醒的时间段。四年前的这个时候他第一次遇到了Echo。四年后Echo还在。

他把新方向写在了一个DESIGN.md的更新里：

> Pulse is not a React alternative. It never was.
>
> Pulse is a lightweight view layer for developers who want:
> - A runtime-only virtual DOM without a build step
> - Simple component APIs without JSX or transpilation
> - Small bundle size (targeting < 15KB gzipped)
> - Framework-agnostic design — works with any backend, any build tool, any other libraries
>
> We respect React and the problems it solves. We also believe there is room for approaches that prioritize simplicity over ecosystem completeness. Pulse is for the developers who value that.

他把这段话发给陆辰看。陆辰回复了一句话：“That’s clear. That’s you.”

---

八月中旬。Pulse 2.0的alpha版本完成。

代码量从8000多行减少到了约5200行——删掉了哪些？服务端渲染的完整实现（保留了一个可选的插件接口）、内置的路由器（变成了一个独立的pulse-router包）、复杂的模板编译器（运行时不需要）。保留了哪些？虚拟DOM引擎、组件系统、状态管理、事件系统、diff算法——每一个都是Pulse的核心。

体积：从约45KB gzipped降到了约13KB。和React相比——React在2013年的gzipped大小约为50KB左右，不包括可选的插件生态。

文档重写：从“Pulse是一个声明式UI框架”变成了“Pulse是最轻量的方式让你的UI响应数据”。

他在发给贡献者的邮件中写：

> Pulse 2.0 represents a strategic pivot, not a surrender. We are focusing on what Pulse does best — runtime rendering, minimal overhead, and framework-agnostic design — and removing the features where we were spread too thin. This is not a smaller Pulse. It’s a sharper one.

markus第一个回复：“I love this direction. Smaller surface area means fewer bugs, easier maintenance, and a clearer identity. Ship it.”

---

九月。新学期。大四。

开学那天，林一走进教室——不是去上课，是去办理大四的一些手续。路过布告栏的时候，习惯性地扫了一眼。上面贴着各种通知、考研辅导班广告、招聘宣讲会信息。腾讯校园招聘——10月15日。阿里巴巴技术开放日——10月20日。这些通知以前和他无关——他原计划是继续读研或者做独立开发者。但现在他看着这些通知，第一次认真地想：如果Pulse只能是一小群人的选择，那我用什么来维持生活？他约了周默聊这件事。线下。
