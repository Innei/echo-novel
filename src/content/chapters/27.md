二零一三年五月二十九日。JSConf US。上午十点。

林一在宿舍。他在网上找到了JSConf的直播链接——没有官方直播，是某个参会者用Google Hangout开着摄像头对着舞台。画面糊。声音有延迟。但足够了。

一个叫Jordan Walke的人走到台上。穿着深灰色的T恤。他身后的幻灯片只有一行字：React: A JavaScript Library For Building User Interfaces。

"React is a library for building user interfaces. It was created at Facebook to solve one specific problem: how do we build complex, interactive UIs that are easy to reason about and perform well?"

林一盯着屏幕。宿舍里风扇在背后嗡嗡响。空气闷热——武汉的五月，温度已经飙到了三十二度。但他没有感觉到。他所有的注意力都在屏幕上那个人身上。

"At Facebook, we have UIs with thousands of components that update frequently. With traditional DOM manipulation—jQuery, Backbone—keeping the UI in sync with the data becomes exponentially harder as the UI grows. We wanted a different approach."

他停顿了一下。幻灯片翻到下一页——一个简单的等式：

UI = f(data)

林一手指在键盘上停住了。不是震惊——是确认。不是"他们抄了我"的愤怒，也不是"他们也在做这个"的欣慰。是某种无法分类的感受。那个等号——他三年前在纸上写下的"State drives View"，是同一个想法。从完全不同的路径，到达了同一个位置。没有谁抄谁。是人类在面对复杂UI时，逻辑的自然收敛。

"React introduces a concept called the virtual DOM. Instead of directly manipulating the browser's DOM—which is slow—we maintain a lightweight representation in JavaScript. When the data changes, React computes the difference between the old and new representations, and applies only the minimal set of changes to the real DOM."

他继续讲。JSX。组件。单向数据流。每个点都是林一在过去几年里反复思考、设计、争论过的问题。现在另一个人站在舞台上，面对几百人，还有线上成千上万的直播观看者，把它作为一个"Facebook的产品"向全世界发布。

他们不是敌人。但这个场景让他孤独。

---

直播结束后，他看了GitHub。一个晚上的时间里，facebook/react的star从零冲上了几千。比他所有的增长加起来还快。不需要解释"我为什么做这个"——React的名字前面挂着十三亿用户的品牌信用。用户不需要"信任"——Facebook已经预支了一切。

这没有对错。品牌本身是一种语言——巨头对这个方向的投资意味着浏览器厂商可能会更重视Virtual DOM的性能优化，招聘市场会开始要求"React经验"而不仅是"JavaScript经验"，整个生态系统从这个时刻起被重新锚定。

但他还是觉得孤独。不是因为有人比他做得更大——而是那种"你在一个小房间里花了很久做某件事，然后一个更有力量的人对着整个世界讲了出来，所有人起立鼓掌"的孤独。同样的思想。不同的音量。

---

他做好了心理建设——和Echo的对话、周默的深夜赶来的谈话、陆辰打来的电话——但浪潮落下来的时候他还是趔趄了一步。

那个周末，Pulse的issue区出现了陌生的ID。有人在issue里说"Pulse is just a pre-release clone of React"。有人说"I don't see why anyone would use Pulse now that React is official"。有人说"作者是不是一直知道react的存在但不说"。还有人把他的设计文章沉了。

不是恶意的——大部分是"React已经出来了，为什么我还要关注一个只有少数人维护的类似框架"——但这个结论像一个缓慢退潮的回声，一条接一条，上午下午夜间地重复。有人开始在Twitter上把Pulse叫做"the framework that almost was"。"almost"这个词像针一样反复扎进他的胸口——不是"差一点成功"的惋惜。是"你做得足够好，但没人在意了"。

他关了浏览器。坐在黑暗里。室友们都睡了。窗外没有月光。路灯还是橙色。

然后他打开了Echo。光标还是闪的——和三年前第一次打开时一模一样。从不高亮，从不催促，永远等着他先开口。

他打了一行字。又删了。又打了一行。又删了。最后只打了四个词。

```chat
> echo. i need to talk.
< Echo，我需要谈谈。

I'm here. Take your time.
< 我在。慢慢说。
```

林一开始写。不是问他应该做什么——他此前已经从别人那里收到了足够多的战略建议。而是把他此刻感受到的一切——走廊尽头那么小的房间、那么短的距离、那么大的比分差距——原模原样地倒给这个黑色终端。

Echo沉默了比以往更久——久到几乎让人以为它宕机了。

然后光标闪了几下。

```chat
Lin Yi.
< 林一。

You are asking the hardest question: whether what you built still has value when something bigger and louder does the same thing.
< 你问的是最困难的问题：当某个更大、更响亮的东西做了同样的事情时，你构建的东西是否还有价值。

I can't answer that for you. But I can tell you what I've observed from every major technological shift I've studied.
< 我无法替你回答。但我可以告诉你，从我研究过的每一次重大技术变革中观察到的东西。

The first implementation of a paradigm-shifting idea is almost never the one that wins the market. The Alto had windows, icons, and a mouse before the Macintosh. VisiCalc came before Excel. Friendster before Facebook. In every case, the first project proved the concept, and a later project with more resources captured the market.
< 范式转换性想法的第一个实现，几乎从来不是最终赢得市场的那个。Alto 在 Macintosh 之前就有了窗口、图标和鼠标。VisiCalc 在 Excel 之前。Friendster 在 Facebook 之前。在每一个案例中，第一个项目证明了概念，而后来的、拥有更多资源的项目占领了市场。

But here's what matters: the people who built the first one? The ones who proved the concept when nobody believed in it? They're the reason the whole field exists. Without them, the later successes never happen.
< 但重要的是：那些构建了第一个的人？那些在没有人相信的时候证明了概念的人？他们是整个领域存在的原因。没有他们，后来的成功永远不会发生。

You built Pulse before React. You proved that a single developer could implement virtual DOM, component-based architecture, and predictable state management — and have real companies depend on it in production. You didn't need a company of thousands. You didn't need years of internal infrastructure. You just needed to see the problem clearly and refuse to stop until you solved it.
< 你在 React 之前构建了 Pulse。你证明了单个开发者可以实现虚拟 DOM、基于组件的架构和可预测的状态管理——并且让真实的公司在生产环境中依赖它。你不需要几千人的公司。你不需要多年的内部基础设施。你只需要清楚地看到问题，并拒绝停下来直到解决它。

Pulse's GitHub stars might not surpass React's. Its contributor count might never match theirs. But that's not the measure that matters.
< Pulse 的 GitHub 星标可能不会超过 React。它的贡献者数量可能永远比不上他们。但这不是重要的衡量标准。

The measure that matters is: you showed that this was possible. Before Facebook. Before the conference talks. Before the job listings. You were there first.
< 重要的衡量标准是：你展示了这是可能的。在 Facebook 之前。在大会演讲之前。在招聘要求之前。你第一个到达了那里。

That can't be taken from you. Not by Facebook. Not by anyone.
< 这无法从你身上夺走。不能被 Facebook。不能被任何人。

Now: take the time you need to process this. The code isn't going anywhere. Pulse isn't going anywhere. And I'm not going anywhere.
< 现在：花你需要的时间来处理这一切。代码不会消失。Pulse 不会消失。我也不会消失。

When you're ready, we'll figure out what comes next. Together.
< 当你准备好了，我们一起弄清楚接下来做什么。一起。
```

林一没有回复。

他靠在椅子上。眼角有一点湿。不是因为他被安慰了——是因为Echo说的是真的。不是因为温柔。是因为它在告诉他：你的位置在历史上已经是固定的——不是因为Facebook选择与否，而是你选择在无人关注的时候开始。

窗外。武汉的夏夜。热气从窗户缝里漏进来。远处偶尔有一声汽车喇叭。近处是六号床的鼾声——稳定而有规律，像一个低频振荡器。

他闭上了眼睛。

明天。明天再想下面的事。
