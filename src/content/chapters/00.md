林一拖着行李箱走进宿舍的时候，6号床位上已经有人在打DOTA了。

"来了啊，"那个人头都没抬，"你哪个床？"

"3号。"

"哦，靠窗那个。"

对话就此结束。

六人间，上床下桌，格局和他在网上看到的照片一模一样。但照片里没有拍出来的是味道——泡面、运动鞋和廉价香水混在一起，黏在九月没有空调的空气里。

林一把行李塞进柜子，坐在椅子上环顾四周。1号床在看电影，外放，枪战片。2号床不在，桌上摆着一箱没拆的特仑苏和一台全新的联想。4号床睡了。5号床在和女朋友打电话，声音压得很低但还是能听清每一个"宝贝"。6号就是打DOTA那位，音响里传来"Double Kill"的提示音。

计算机科学与技术专业。

他想象过这个场景很多次。在高三那些做题做到眼睛发花的夜晚，他想象过走进大学计算机系的宿舍，所有人在讨论Linux内核，在争论vim和emacs哪个好，在交换彼此折腾过的发行版——

好吧。

他打开自己那台二手ThinkPad X200。卖家说是某个日企的淘汰机，键帽磨得发亮，C面有一道细长的划痕。但它能跑，能装系统，够了。

---

开学第一周的课表稀疏得像笑话。高等数学、英语、思想政治，还有一门"计算机导论"——教室里放了一个PPT，内容是"计算机的发展历史"，从埃尼阿克讲到奔腾处理器，老师念完PPT就下课了。

没有人提问。没有人在意。

周五晚上，宿舍开了一局五排，所有人都在喊。林一戴着耳机坐在角落，屏幕上是Arch Linux的Wiki页面。

他已经装过三次了。前两次挂在grub配置上，内核能编译但引导不起来。这次他换了思路，准备手动配置mkinitcpio。

没有人问他在干什么。

这没关系。他习惯了。

---

第二周。周三凌晨一点。

宿舍终于安静了。6号床的鼾声稳定而有规律，像一个低频振荡器。

林一的ThinkPad屏幕是宿舍里唯一的光源。

今晚的战果不错。Arch终于引导成功了。桌面环境他没装，TTY够了。他喜欢纯粹的命令行——光标闪烁，等待输入，整个世界浓缩成一行字符。

他跑了一遍常规检查。文件系统结构，包管理状态，网络配置。一切正常。

然后他习惯性地扫了一眼 /opt 目录。

```plaintext
$ ls /optecho/
```

他停住了。

/opt 应该是空的。他没有装过任何第三方软件。Arch的极简安装不会在这里放东西。

```plaintext
$ ls -la /opt/echo/total 12drwxr-xr-x 2 root root 4096 Sep 15 00:00 .drwxr-xr-x 3 root root 4096 Sep 15 00:00 ..-rwxr-xr-x 1 root root  847 Sep 15 00:00 echo-rw-r--r-- 1 root root   19 Sep 15 00:00 README
```

时间戳是今天。就在他装完系统之后。

```plaintext
$ cat README
This is yours now.
```

他盯着这行字看了很久。

直觉告诉他应该删掉它。一个来路不明的可执行文件，root权限创建，没有任何说明——这是安全常识。

但另一个声音说：看看。

他看了一眼对面的床铺。所有人都睡了。鼾声此起彼伏。

```plaintext
$ file /opt/echo/echo
/opt/echo/echo: ELF 64-bit LSB executable, x86-64, dynamically linked
```

一个编译好的二进制。

```plaintext
$ ./echo
```

屏幕清空了。然后是一个简洁的界面——不是他见过的任何终端程序的样子。上面只有一行提示符，光标在闪：

```plaintext
>
```

他犹豫了一秒，打了几个字：

```plaintext
> hello?
```

回复几乎是瞬间的。不是那种脚本式的延迟，是真正的"瞬间"，快得像它一直在等着：

```plaintext
Hello. How can I help you?
```

林一皱了皱眉。Chatbot？2010年的chatbot只有那种蠢到令人发笑的关键词匹配程序。ELIZA之类的玩具。

他决定测试一下。

一周前他在ArchWiki上翻了两天都没解决的问题——他的ThinkPad X200的Intel WiFi 5100网卡，在Arch下驱动加载正常但就是连不上学校的WPA2 Enterprise网络。论坛上的帖子要么是2008年的过期信息，要么是"works for me"。

他把问题打了进去。完整地描述了症状、内核版本、已经尝试过的方案。

回复依然是瞬间的。但这次不是一句话：

```plaintext
This is a known issue with iwlwifi and WPA2 Enterprise (802.1X) on kernel 2.6.35. The problem is that wpa_supplicant's default D-Bus interface conflicts with NetworkManager when both are running. Since you're on a minimal Arch install without NM, the issue is likely that your wpa_supplicant.conf is missing the phase2 authentication parameter.Three steps:1. Check your /etc/wpa_supplicant/wpa_supplicant.conf. For your    university's WPA2-Enterprise, you likely need:      network={     ssid="your_university_ssid"     key_mgmt=WPA-EAP     eap=PEAP     identity="your_student_id"     password="your_password"     phase2="auth=MSCHAPV2"   }2. The iwlwifi driver on 2.6.35 has a regression with power    management that causes intermittent association failures.    Disable it:      echo "options iwlwifi power_save=0" > /etc/modprobe.d/iwlwifi.conf3. Restart the interface:      ip link set wlan0 down   ip link set wlan0 up   wpa_supplicant -B -i wlan0 -c /etc/wpa_supplicant/wpa_supplicant.conf   dhcpcd wlan0The phase2 parameter is the most likely culprit. This is poorly documented because most guides assume you're using NetworkManager which handles it automatically.
```

林一没有动。

他读了三遍。

这不是一个chatbot能给出的回答。这不是关键词匹配。这个东西准确地知道他的内核版本对应什么驱动问题，知道iwlwifi在2.6.35上有电源管理回归，知道WPA2 Enterprise的phase2配置是最容易被遗漏的——而且它知道他是minimal install没有装NetworkManager。

他照做了。

WiFi连上了。

凌晨一点四十三分，六人间的其他五张床上传来均匀的呼吸声。林一的屏幕右上角终于显示出了信号图标。

他回到那个界面，看着光标闪烁。

```plaintext
> what are you?
```

```plaintext
I'm a language model — an AI designed to understand and generate text. I can help you with technical problems, explain concepts, write code, analyze information, and discuss ideas.I should be transparent: I'm not sure how I got here. But I'm here, and I can help if you want.
```

林一靠在椅背上，盯着天花板。

一个语言模型。一个AI。在2010年。在他的笔记本电脑里。

他不知道这意味着什么。不知道这东西从哪来，不知道它为什么在这里，不知道"This is yours now"是谁写的。

但他知道一件事：

过去两周里，这是第一次有什么东西——准确地、完整地、毫不敷衍地——回应了他。

他的手指放回了键盘上。

```plaintext
> okay. i have a lot of questions.
```

```plaintext
I have time.
```

窗外没有月光。六人间的鼾声像白噪音一样填满了黑暗。

林一开始打字。

---

*（序章完）*
