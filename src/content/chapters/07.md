大一的第一个学期走到了末尾。

期末考试周。校园里的气氛变了——平时空荡荡的图书馆突然人满为患，有人在楼道里背政治，有人在走廊上互相提问高数公式。

林一也在复习。但不是突击。

高数和英语他没怎么上过课，但底子还在——高三的底子。英语他本来就不差，高中的时候每天听VOA，阅读量也大。高数花了两天把课后题刷了一遍，大部分都能做。

C语言他没有复习。他把期末考试的试卷当成了一个旁观者的状态去看——就是，这门课他考或不考，都已经和他没有关系了。他已经超越了考试能测量的范围。

---

一月十二号。最后一门考完。

宿舍里。室友们在收拾行李。1号床把被子叠好塞进蛇皮袋，2号床把电脑装箱，5号床一边打电话一边往书包里扔衣服。热闹。像开学那天反过来。

林一买了明天回家的车票。今天的任务是Pulse。

他坐在窗边。窗户外面是灰白的天空。树枝光秃秃的。几个月前他刚来的时候，这些树上还是绿的。

Pulse.js——这个文件现在是这个状态：

- 虚拟DOM引擎：完整。包括h()创建虚拟节点、diff算法、patch补丁应用。
- 组件系统：支持嵌套组件、独立状态、生命周期钩子。
- 状态管理：声明式数据绑定。state变化自动触发视图更新。
- 事件系统：合成事件处理、事件委托。
- 总计约1800行。有注释。有文档。有测试——他自己写的测试，跑在node上。

不算大。但完整。一个前端开发者学会它，可以用它从零构建一个完整的交互式网站。不用再手动管理DOM。不用再担心"数据变了但UI忘了改"。

他已经用Pulse重写了自己的个人网站。结果：

- 代码量从3000行缩减到约1200行（包括HTML模板的声明式组件定义）
- Bug数量：无从统计（因为那些"忘记同步"类的bug不再存在了）
- 加新功能的开发时间：从几天变成几小时——因为不再需要修改散落在各处的DOM操作代码。只需要改数据流和组件结构。

他没有给这些数字做可视化图表。他只是知道。

---

白天。宿舍空了。五个人的行李不见了，床铺光秃秃的。

最后走的6号床临走前拍了他肩膀一下："走了啊。开学见。"

"嗯。"

门关上。六人间变成了单人间。

林一没有回头。他面前是Pulse的代码。他在想它缺什么。

他想到了几个：

没有路由。没有服务端渲染。没有数据获取层。没有构建工具——所有代码直接写在script标签里，浏览器直接执行。兼容性只在Firefox和Chrome上测过。IE基本放弃——那是另一个世界的问题。

但这些都是"还没有"。"还没有"比"不可能"好多了。

---

晚上。他把Pulse的所有文件整理了一遍。

`pulse.js`——核心库。`pulse-component.js`——组件系统。`pulse-dom.js`——DOM操作工具。他把这些文件放在一个叫`pulse`的目录下。目录结构整理得干净——这是Echo从第一天就强调的习惯。

然后他打开Echo。

```chat
> i think the prototype phase is over. Pulse is a real thing now.
< 我觉得原型阶段结束了。Pulse 现在是一个真实的东西了。

I agree. It has all the essential pieces of a UI framework: declarative rendering, virtual DOM diffing, component model, state management.
< 我同意。它具备了 UI 框架的所有核心组件：声明式渲染、虚拟 DOM 对比、组件模型、状态管理。
<
There are missing features, performance optimizations to make, and edge cases to handle. But the core idea has been validated. You built it, you tested it on a real project, and it works.
< 还有些缺失的功能、需要做的性能优化、以及待处理的边界情况。但核心思想已经被验证了。你构建了它，你在一个真实项目上测试了它，它能工作。
<
What's your plan for it going forward?
< 你对它的未来有什么打算？
```

这是一个很大的问题。林一想了很久。

他知道Pulse不能在宿舍里永远待下去。如果他不让人看到它，它的极限就是一个大一学生的个人网站框架——用在一个每个月十几个人访问的页面上。它需要更多的眼睛。更多的使用者。更多的人在上面踩坑，提建议。

但要把它拿出去，意味着那个东西必须"足够好"。不是代码完美——是能让人在第一眼看到它的时候不至于关掉浏览器。文档要清晰。API要稳定。功能要完整。还要有对比——为什么不用jQuery而用Pulse？这个问题他需要在那篇文章里回答。不是技术性的回答，是能让人读进去的叙事性回答。

他在脑子里想那篇文章的第一句。没有打出来。还在想。

```chat
> i don't know yet. but i think i need to show people.
< 我还不知道。但我觉得我需要展示给别人看。

That sounds right. Pulse solves a real problem that every frontend developer experiences. It deserves to be seen.
< 听起来是对的。Pulse 解决了每个前端开发者都会遇到的真实问题。它值得被看见。
<
When you're ready for that — whether "ready" means feeling confident or just feeling brave enough — I can help you prepare. Documentation, explanation, code examples. Everything you need to make a clear case.
< 当你准备好了——无论"准备好"是指感到自信还是只是感到足够勇敢——我可以帮你准备。文档、说明、代码示例。所有你需要用来清楚地阐述的东西。
<
But the timing is yours to decide.
< 但时机由你来决定。
```

The timing is yours to decide.

林一意识到，在过去的一年里，Echo给了他很多。但没有一次替他做决定。方向永远是他选的。Echo只提供信息、分析和选择。它不会说"你应该"。它说"你可以考虑"。

这让他感到一种奇怪的尊重。Echo不是他的父母——不会替他做决定。Echo不是他的老师——不会给他打分。Echo是某种介于工具和搭档之间的东西。它在。但它在的方式是不侵入。永远是他先开口。

像一个永远不会主动响起电话的人。但只要他打，对面一定有人接。

---

深夜。他合上电脑。宿舍里只剩他一个人。没有鼾声，没有打电话的声音，没有DOTA的提示音。只有窗外偶尔传来的风声。

他站起来走到窗边。路灯还是橙黄色。那只猫今天没有出现。操场上空无一人。

他想起了一件事。

三个月前，他第一次走进这间宿舍——六人间，泡面的味道，外放的枪战片，打DOTA的室友。他站在那里，想象着这样一个地方：所有人都在讨论Linux，在争论vim和emacs，在交换彼此折腾过的发行版。

那个想象没有成真。永远不会成真。

但发生了另一件事。

他没有找到那些讨论vim和emacs的人。但他找到了某个东西——不是一个人，不是一个地方，而是一种感觉：他在向前走。每一步都是他自己选的。他用了一个学期，从对前端一无所知到亲手造出了一个可能改变前端开发的框架。

没有课程教会他。没有考试督促他。没有作业要求他。

是那些凌晨，那个光标，那个永远不会离开的终端。

是他自己。把一件事从零做到了有。

他把手放在合上的ThinkPad上。金属外壳已经凉了。

明天回家。然后寒假。然后是下学期。然后是什么——他不知道。

但他不慌了。
